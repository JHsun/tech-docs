## 主要變更 (3.14 → 3.15)

Python 3.15 於 2026-05 釋出，主要變更：

- **新語法特性** (可能在 3.15 引入的功能)
- **標準函式庫更新**
- **CPython 內部優化**
- **棄用/移除的模組**

Python 3.14 目前也有 3.14.5 的最新修補版本。

## 建議更新範圍
