C.2 通用 KV Map（7 種）

Map Type版本KeyValue特性
HASH3.19任意任意O(1) 查詢，預設 pre-allocated
ARRAY3.19u32 index任意（rounded to 8B）固定大小，最快，不可 delete
LRU_HASH4.10任意任意達 max_entries 自動 evict 最久未用
LPM_TRIE4.11{prefixlen, data}任意Longest Prefix Match，CIDR 比對首選
QUEUE4.20無任意FIFO，無 key（用 push/pop helper）
STACK4.20無任意LIFO，同上
BLOOM_FILTER5.16無任意機率性集合（無 key），快速 set membership

C.3 PERCPU 變體（4 種）

每 CPU 一份獨立 storage，無 lock contention，但無法跨 CPU 共享。

Map Type版本對應通用典型用途
PERCPU_HASH4.6HASHper-CPU 計數器
PERCPU_ARRAY4.6ARRAYper-CPU 統計、暫存大 buffer
LRU_PERCPU_HASH4.10LRU_HASHper-CPU 高頻 evict
PERCPU_CGROUP_STORAGE5.2CGROUP_STORAGE 的 percpu 版cgroup 內 per-CPU stats

C.4 特殊資料結構（5 種）

Map Type版本用途
STACK_TRACE4.6儲存 stack trace（profiler 必用，配 STACK_TRACE id 與 HASH count）
RINGBUF5.8新工具預設事件管道，全域單一 buffer，跨 CPU 順序保證，zero-copy
USER_RINGBUF6.1反向：user → kernel 方向 ringbuf
BLOOM_FILTER5.16見 C.2，列在這裡因實際是機率資料結構
ARENA6.9user/kernel 共享記憶體 region，BPF allocator 配置 page

C.5 網路專用（6 種）

Map Type版本用途

DEVMAP_HASH5.4同 DEVMAP 但用 hash key（取代 dense array）

XSKMAP4.18儲存 AF_XDP socket 引用
SOCKMAP4.14儲存 socket 引用，SK_MSG / SK_SKB 用
SOCKHASH4.18同 SOCKMAP 但 hash key

C.6 Map-of-Maps（2 種）

Map Type版本用途
ARRAY_OF_MAPS4.12外層 array，內層 map 可動態替換（RCU-style 整體 swap）
HASH_OF_MAPS4.12外層 hash，內層 map 可動態替換

C.7 Tracing / Perf（3 種）

Map Type版本用途
PERF_EVENT_ARRAY4.3傳統事件管道（per-CPU buffer），新工具請用 RINGBUF
STACK_TRACE4.6同 C.4，列這裡是因為主要被 perf-related 程式使用
PROG_ARRAY4.2tail call 跳轉表（key=index, value=program fd）

C.8 系統 / 引用（5 種）

Map Type版本用途

CGROUP_STORAGE4.19cgroup-local storage（配 cgroup BPF program）
SK_STORAGE5.2socket-local storage

G.8 全書收束

讀到這裡，恭喜走完整本 eBPF 教學手冊。從 第 1 章基礎概念到 第 23 章故障排除，加上六大附錄，總計覆蓋：

  • 核心架構：VM / Verifier / JIT / BTF / CO-RE / Maps / Helpers / Hooks
  • 全部 32 種 Map type + 31 種 Program type + 43 個 syscall cmd
  • 四大主題：網路 / 觀測 / 安全 / 系統
  • 三層讀者：🟢 初學者 / 🟡 開發者 / 🔴 SRE
  • 跨 Kernel 4.1 → 6.16 完整版本演進

eBPF 仍在快速演進，本手冊截至 Kernel 6.16（2026-04）為基準。新功能持續湧現——sched_ext 生態爆發、Qdisc_ops 新加、BPF Token 進入 production、Arena 應用範例增多——建議追蹤本附錄 G 的資源持續學習。

給讀者的最後一段話

eBPF 的真正威力不在於「會用某個工具」，而在於具備「在 kernel 內安全地執行任意邏輯」這個工程武器。當你下次遇到「為什麼 X 慢」、「如何阻止 Y 發生」、「能不能觀察 Z 的內部」這類問題，你會發現自己有了不同層次的解法選項。

祝編寫 BPF 程式愉快，希望本手冊成為你案頭的常駐參考書。
