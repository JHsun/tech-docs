WebAssembly
從入門到生產

一份為後端、平台工程師與架構師量身打造的學習路徑——從位元碼基礎走到 Component Model、邊緣部署與高可用叢集。

v1.0 May 2026 Wasm 3.0 · WASIp2 Stable 10 modules + Capstone

WebAssembly 已不再只是「瀏覽器加速器」。2026 年的 Wasm 是一個跨語言、跨平台、能力導向（capability-based）的通用 runtime，正在邊緣運算、Serverless、Service Mesh 與外掛系統中重新定義部署單位。本 handbook 帶你從位元碼層出發，理解沙箱模型、WASI 標準、Component Model，最終能設計可觀測且高可用的生產系統。

「Write once, run anywhere safely」——Java 當年的夢，Wasm 是目前最有機會兌現的候選人。

PROLOGUE · 01如何使用本 Handbook

本書設計為「漸進式深入」結構。每個 module 是獨立 HTML 檔，可單獨閱讀但建議依序學習；前序章節建立的概念會在後續被反覆引用。你不需要把所有 module 一次讀完，可以依需求挑章節：

  • 剛接觸 Wasm：M01 → M02 → M03，建立核心心智模型。
  • 準備開始實作：M05 → M06，挑語言、挑 runtime。
  • 規劃生產部署：M08 → M09 → M10，部署、觀測、HA 一條龍。
  • 跨語言架構設計：M04 → M07，深入 WASI 與 Component Model。
  • 整合練習：完成 Capstone Project。
學習路徑建議 完整走完約 40–50 小時。建議每天 1–2 小時、每週 2–3 個 module 的節奏，搭配動手實作能在 6–8 週完成。

PROLOGUE · 02目標讀者與前置知識

適合誰閱讀

  • 已有後端、雲端、平台工程經驗，想評估 Wasm 是否值得導入的工程師與架構師。
  • 想將既有服務（Node.js BFF、Go microservice、Rust crate）以 Wasm 重新打包部署到邊緣的開發者。
  • 負責 Service Mesh、API Gateway、外掛系統，想用 Wasm 取代 Lua / 自製 sandbox 的平台團隊。
  • 對「沙箱化的可攜執行單位」如何挑戰容器既有疆界有興趣的技術決策者。

需要的前置知識

  • 至少一門系統語言實作經驗（Rust、Go、C/C++ 任一）。
  • 熟悉 Linux 命令列、Docker、kubectl 基本操作。
  • 了解 HTTP、TLS、DNS、基本網路概念。
  • 讀過 12-factor app 並理解無狀態服務設計原則。

不需要先了解

  • WebAssembly 本身——本書從零開始。
  • 瀏覽器內 JS 整合細節（本書聚焦伺服器 / 邊緣 / 嵌入式場景）。
  • Component Model 的內部 ABI 細節（會在 M07 從應用視角講解）。

PROLOGUE · 03實作環境準備

本 handbook 所有動手實作都可在 Linux、macOS、或 Windows + WSL2 環境執行。建議事先安裝以下工具：

必裝工具

bash 
# Rust 工具鏈（用於寫 Wasm 模組）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup target add wasm32-wasip1 wasm32-wasip2 wasm32-unknown-unknown

# wasm-tools（檢視、操作 .wasm binary）
cargo install wasm-tools

# Wasmtime CLI（執行、編譯 .wasm）
curl https://wasmtime.dev/install.sh -sSf | bash

# Go（用於寫宿主，搭配 wazero）
# https://go.dev/dl/  安裝 Go 1.22+

# Spin CLI（serverless 框架，後段會用）
curl -fsSL https://developer.fermyon.com/downloads/install.sh | bash

# TinyGo（編譯較小的 Wasm，選用）
# https://tinygo.org/getting-started/install/

# Docker、kubectl（部署相關章節會用）

驗證安裝

bash 
rustc --version              # rustc 1.78.0+
wasm-tools --version         # wasm-tools 1.x
wasmtime --version           # wasmtime 26.x+（建議）
go version                   # go1.22+
spin --version               # spin 3.x+

CHAPTERS章節索引

Module 01 · Foundation

基礎概念與生態地景

追溯 Wasm 從 asm.js 到 3.0 的演進、釐清在瀏覽器 / 伺服器 / 邊緣 / 嵌入式四種定位的差異，建立對 Bytecode Alliance、W3C、CNCF 三大治理組織的認識。

~3h Module 02 · Foundation

Wasm 核心模型與執行原理

深入 stack-based VM、linear memory、module/instance 的關係。讀懂 WAT 文字格式，掌握編譯流程（source → LLVM → .wasm → validate → JIT/AOT → exec），用 wasm-tools 解剖實際 binary。

~4h Module 03 · Core

沙箱與能力導向安全模型

區分 permission-based 與 capability-based 的根本差異，動手用 wazero 實作 L7 / L4 proxy 宿主，掌握 allowlist 設計、SSRF 防護與粒度權衡。

~3h Module 04 · Core

WASI 與系統介面演進

追蹤 WASI Preview 1 → 2 → 3 的演進，理解 WIT 介面定義語言與 Canonical ABI，讀懂 wasi:cli、wasi:http、wasi:sockets 等 World 定義。

~3h Module 05 · Practical

語言生態與工具鏈

分辨 directly-compiled、GC-based、interpreter-on-Wasm 三類語言支援模式，用 Rust、Go/TinyGo 各寫一個相同 API 的 Wasm 模組，理解「直接可跑」的真正定義。

~4h Module 06 · Practical

Runtime 比較與自架方案

系統比較 Wasmtime、wazero、WasmEdge、Wasmer、WAMR 等開源 runtime 與 Spin、wasmCloud 等應用框架，學會依宿主語言、目標環境、合規需求做選型。

~4h Module 07 · Advanced

Component Model 與跨語言組合

區分 core module 與 component，用 WIT 定義介面、產生 Rust / JS / Python 綁定，用 wasm-tools compose 把多個 component 串接。

~4h Module 08 · Advanced

取代 Web API：HTTP 服務部署

五種部署路線（Serverless、K8s + containerd-shim、自架 runtime、Proxy filter、嵌入式），用 Spin + SpinKube 部署一個生產級 HTTP API，處理狀態外置與能力宣告。

~5h Module 09 · Production

可觀測性建構

區分宿主層觀測 vs Wasm 內主動回報兩條路線，實作 trace context 跨 Wasm 邊界傳遞，整合 OpenTelemetry collector、Tempo、Loki、Mimir、Grafana。

~4h Module 10 · Production

負載平衡、叢集與高可用

設計多副本、跨 node、跨區的 Wasm 叢集架構，實作 instance pooling、AOT 快取、graceful shutdown，處理 fuel quota、OOM、circuit breaker 等失敗模式。

~5h Capstone · Integration

期末實作：邊緣可程式化 API Gateway

整合前 10 章所有概念，自架一個讓使用者可上傳 Wasm component 作為中介過濾器的 API Gateway，含能力導向授權、實例池、AOT 快取、OTel 整合與 K8s 部署。

~8h Appendix · Reference

中英對照詞彙表

本 handbook 使用的所有專有名詞中英對照，含定義、出處、相關章節索引。
