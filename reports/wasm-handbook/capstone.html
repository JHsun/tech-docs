OVERVIEW專案總覽

專案描述

建立一個 邊緣可程式化 API Gateway——核心功能是讓使用者上傳自己編寫的 Wasm component（用任何支援的語言），平台動態載入這些 component 作為「中介過濾器」（middleware filter），插入到 HTTP 請求處理 pipeline 中。

典型使用情境：

  • SaaS 提供商想讓客戶在請求進入後端前做自訂處理（authentication、rate limit、transformation、auditing）
  • 多租戶平台需要允許各 tenant 注入不同邏輯
  • 邊緣節點需要動態加載業務邏輯而不重啟服務

商業類比

你做的東西概念上類似：

  • Cloudflare Workers——但你自架，控制完全在自己手裡
  • Fastly Compute@Edge——但開源、可植入既有架構
  • Envoy + Proxy-Wasm——但更輕量、focus 在 API 場景
  • Shopify Functions——但通用、不綁定特定 SaaS

REQUIREMENTS功能要求

必要功能（80% 分數）

1. Gateway 核心

  • 用 Rust + Wasmtime 自架（不可用 Spin / wasmCloud 等現成框架）
  • HTTP server 用 axum 或 hyper
  • 支援 routing：path、method、host 匹配
  • 支援 upstream proxy：把請求轉發到下游 backend
  • 支援 component pipeline：每條 route 可關聯一條或多條 Wasm filter

2. Wasm Component 接口

  • 定義 WIT 介面 gateway:filter，至少支援：
    • on-request(req: http-request) -> filter-action
    • on-response(resp: http-response) -> filter-action
  • filter-action 支援：continue、modify、reject、redirect
  • 提供 Rust SDK 簡化客戶寫 component
  • 提供至少一個 example filter（如 JWT validator、rate limiter）

3. 能力導向授權

  • 每個 component 在配置中宣告 capability（allowed-outbound-hosts、kv-stores、secrets）
  • Gateway 驗證 component 不能存取未授權能力
  • SSRF 防護：拒絕內網 / loopback / link-local IP
  • 支援 per-tenant capability 隔離

4. 實例池 + AOT 快取

  • Component instance pool 預熱機制
  • 用 Wasmtime PoolingAllocator
  • 支援 AOT 預編譯（從 OCI registry 拉預編譯版）
  • 暴露 pool metrics：available、in-use、created、destroyed

5. OTel 整合

  • 每個 HTTP 請求產生完整 trace：server span → filter span(s) → upstream span
  • 跨 Wasm 邊界正確 propagate trace context
  • 標準 metric：request 數、延遲分佈、錯誤率、component 執行延遲
  • 結構化 log（JSON），含 trace_id 關聯

6. K8s 部署

  • Helm chart 或 raw YAML
  • HPA 基於 CPU 與請求 QPS
  • PodDisruptionBudget 保證 minAvailable
  • Pod anti-affinity 跨 node 分佈
  • Liveness + readiness probe（含 noop invoke）
  • Graceful shutdown 處理

加分功能（20% 分數）

7. 跨區 Active-Active

  • 支援多區部署
  • 用 CockroachDB / Spanner 之類做跨區 control plane 同步
  • 狀態（rate limiter counter 等）用 Redis Cluster 跨區複製

8. 熱重載

  • 上傳新版 component 後，舊請求繼續用舊版完成、新請求用新版
  • 不需要重啟 gateway process
  • 支援 canary：新版 component 給 5% 流量試跑

9. Admin Web UI

  • 列出所有 routes 與其 filter pipeline
  • 上傳新 component（推到 registry）
  • 查看 component 的 metric、log、trace
  • 動態切換 component 版本

10. 多語言 SDK

  • Rust SDK（必要）
  • TinyGo SDK
  • JavaScript SDK（用 jco）
  • Python SDK（用 componentize-py）

// wit/gateway.wit
package gateway:filter@1.0.0;

interface types {
    record http-request {
        method: string,
        path: string,
        query: option<string>,
        headers: list<tuple<string, string>>,
        body: list<u8>,
        client-ip: string,
    }

    record http-response {
        status: u16,
        headers: list<tuple<string, string>>,
        body: list<u8>,
    }

    variant filter-action {
        // 繼續到下個 filter，傳遞可能修改過的 request/response
        continue-with(http-request),
        continue-response(http-response),

        // 立即回應，跳過後續 filter 與 upstream
        respond(http-response),

        // 拒絕，回 4xx
        reject(record { status: u16, message: string }),

        // 重導向
        redirect(record { location: string, permanent: bool }),
    }

    record kv-error {
        code: u32,
        message: string,
    }

    record outbound-error {
        code: u32,
        message: string,
    }
}

interface kv {
    use types.{kv-error};
    get: func(key: string) -> result<option<list<u8>>, kv-error>;
    set: func(key: string, value: list<u8>,
              ttl-seconds: option<u32>) -> result<_, kv-error>;
    delete: func(key: string) -> result<_, kv-error>;
    increment: func(key: string, delta: s64) -> result<s64, kv-error>;
}

interface outbound {
    use types.{outbound-error, http-request, http-response};
    fetch: func(req: http-request) -> result<http-response, outbound-error>;
}

interface telemetry {
    log: func(level: u32, message: string);
    metric-inc: func(name: string, value: f64,
                     labels: list<tuple<string, string>>);
}

world filter {
    import kv;
    import outbound;
    import telemetry;
    import wasi:clocks/wall-clock@0.2.0;

    use types.{http-request, http-response, filter-action};

    export on-request: func(req: http-request) -> filter-action;
    export on-response: func(resp: http-response) -> filter-action;
}

Gateway 主流程（Rust）

rust 
// 簡化版 gateway 主流程
use axum::{
    body::Body,
    extract::{Request, State},
    http::{HeaderMap, StatusCode},
    response::Response,
    routing::any,
    Router,
};
use std::sync::Arc;
use wasmtime::{component::*, Config, Engine};

struct GatewayState {
    engine: Arc<Engine>,
    routes: Arc<RouteTable>,
    component_pool: Arc<ComponentPool>,
    upstream_client: reqwest::Client,
    otel: Arc<OtelContext>,
}

async fn handle(
    State(state): State<Arc<GatewayState>>,
    req: Request,
) -> Response {
    let (parts, body) = req.into_parts();
    let body_bytes = axum::body::to_bytes(body, MAX_BODY_SIZE).await
        .unwrap_or_default();

    // 1. 從 trace context 還原 OTel parent
    let parent_ctx = state.otel.extract(&parts.headers);
    let span = state.otel.tracer.start_with_context(
        "gateway.request",
        &parent_ctx,
    );

    // 2. 路由匹配
    let route = match state.routes.match_route(
        &parts.method, parts.uri.path(),
    ) {
        Some(r) => r,
        None => return not_found(),
    };

    // 3. 建立 http-request
    let mut wasm_req = build_wasm_request(&parts, &body_bytes);

    // 4. 跑 on-request filter pipeline
    for filter_ref in &route.request_filters {
        let result = run_filter(
            &state, filter_ref, FilterPhase::Request, &mut wasm_req,
            &parent_ctx,
        ).await;

        match result {
            FilterAction::Continue => continue,
            FilterAction::Respond(resp) => return resp.into(),
            FilterAction::Reject { status, message } => {
                return error_response(status, message);
            }
            FilterAction::Redirect { location, permanent } => {
                return redirect_response(&location, permanent);
            }
        }
    }

    // 5. 轉發到 upstream
    let upstream_url = format!("{}{}", route.upstream, parts.uri.path());
    let upstream_resp = state.upstream_client
        .request(parts.method, &upstream_url)
        .headers(parts.headers)
        .body(wasm_req.body)
        .send().await;

    let mut wasm_resp = match upstream_resp {
        Ok(r) => build_wasm_response(r).await,
        Err(e) => return upstream_error(e),
    };

    // 6. 跑 on-response filter pipeline
    for filter_ref in &route.response_filters {
        let result = run_filter(
            &state, filter_ref, FilterPhase::Response, &mut wasm_resp,
            &parent_ctx,
        ).await;
        // ... 處理 result
    }

    // 7. 回應
    build_axum_response(wasm_resp)
}

async fn run_filter(
    state: &GatewayState,
    filter_ref: &FilterRef,
    phase: FilterPhase,
    payload: &mut WasmPayload,
    parent_ctx: &opentelemetry::Context,
) -> FilterAction {
    let span = state.otel.tracer.start_with_context(
        format!("filter.{}.{}", filter_ref.name, phase),
        parent_ctx,
    );

    // 從 pool 取 instance
    let instance = state.component_pool.get(&filter_ref.id).await?;

    // 配置 capabilities
    let host = FilterHost::new(filter_ref, state, span.span_context());

    // invoke
    let result = match phase {
        FilterPhase::Request => instance.call_on_request(payload).await,
        FilterPhase::Response => instance.call_on_response(payload).await,
    };

    // 歸還 instance（pool 內部會視狀況決定 reset / 銷毀）
    state.component_pool.put(filter_ref.id, instance).await;

    result.unwrap_or(FilterAction::Continue)
}

Component pool 設計

rust 
// component-pool.rs
use parking_lot::Mutex;
use std::collections::HashMap;
use tokio::sync::Semaphore;

pub struct ComponentPool {
    engine: Arc<Engine>,
    pools: Mutex<HashMap<FilterId, FilterPool>>,
}

struct FilterPool {
    component: Component,           // 預編譯的 component
    available: tokio::sync::Mutex<Vec<FilterInstance>>,
    semaphore: Arc<Semaphore>,       // 限制總實例數
    max_size: usize,
    use_count: AtomicU64,
    max_uses_per_instance: u64,      // 超過就銷毀重建
}

impl ComponentPool {
    pub async fn get(&self, id: &FilterId) -> FilterInstance {
        let pool = {
            let pools = self.pools.lock();
            pools.get(id).cloned().expect("filter not registered")
        };

        let _permit = pool.semaphore.acquire().await.unwrap();

        // 嘗試從可用 pool 拿
        {
            let mut available = pool.available.lock().await;
            if let Some(inst) = available.pop() {
                let count = inst.use_count.fetch_add(1, Ordering::Relaxed);
                if count < pool.max_uses_per_instance {
                    return inst;
                }
                // 超過使用次數限制，銷毀重建
                drop(inst);
            }
        }

        // pool 空或銷毀後，現場建立新 instance
        FilterInstance::new(&self.engine, &pool.component).await
    }

    pub async fn put(&self, id: FilterId, inst: FilterInstance) {
        let pool = {
            let pools = self.pools.lock();
            pools.get(&id).cloned()
        };

        if let Some(pool) = pool {
            // 嘗試 reset state
            if inst.reset().await.is_ok() {
                let mut available = pool.available.lock().await;
                if available.len() < pool.max_size {
                    available.push(inst);
                    return;
                }
            }
        }
        // 池滿或 reset 失敗：drop
        drop(inst);
    }
}

Capability 強制

rust 
// host-impl.rs - 實作 wit-bindgen 生成的 trait

struct FilterHost {
    filter_ref: FilterRef,
    state: Arc<GatewayState>,
    span: SpanContext,
}

impl gateway::filter::outbound::Host for FilterHost {
    async fn fetch(&mut self, req: HttpRequest)
                    -> Result<HttpResponse, OutboundError>
    {
        // 1. 檢查 capability
        let url = url::Url::parse(&req.url)
            .map_err(|e| OutboundError::invalid_url(e))?;

        let host = url.host_str()
            .ok_or_else(|| OutboundError::missing_host())?;

        let allowed = self.filter_ref.capabilities.allowed_outbound_hosts
            .iter()
            .any(|pattern| match_host(pattern, host));

        if !allowed {
            self.state.otel.metric_inc(
                "gateway.filter.outbound.denied",
                1.0,
                &[("filter", self.filter_ref.name.as_str()),
                  ("host", host)],
            );
            return Err(OutboundError::not_allowed(host));
        }

        // 2. SSRF 防護
        let ips = tokio::net::lookup_host((host, 80)).await
            .map_err(|e| OutboundError::dns_failed(e))?
            .collect::<Vec<_>>();

        for sa in &ips {
            let ip = sa.ip();
            if ip.is_loopback() || ip_is_private(&ip) {
                return Err(OutboundError::ssrf_blocked(ip));
            }
        }

        // 3. 發送（帶 trace context propagation）
        let mut headers = HeaderMap::new();
        for (k, v) in &req.headers {
            headers.insert(k, v.parse().unwrap());
        }
        self.state.otel.inject(&self.span, &mut headers);

        let resp = self.state.upstream_client
            .request(req.method.parse().unwrap(), req.url)
            .headers(headers)
            .body(req.body)
            .send().await
            .map_err(|e| OutboundError::request_failed(e))?;

        Ok(build_response(resp).await)
    }
}

impl gateway::filter::kv::Host for FilterHost {
    async fn get(&mut self, key: String) -> Result<Option<Vec<u8>>, KvError> {
        // tenant 隔離：key 前綴加上 tenant id

Example filter：Rate Limiter

rust 
// example-filters/rate-limiter/src/lib.rs
use bindings::exports::gateway::filter::filter::Guest;
use bindings::gateway::filter::{kv, telemetry, types::*};

struct Component;

impl Guest for Component {
    fn on_request(req: HttpRequest) -> FilterAction {
        // 用 client IP 作 key
        let key = format!("rate:{}", req.client_ip);

        let now_minute = current_minute();
        let counter_key = format!("{}:{}", key, now_minute);

        let count = kv::increment(&counter_key, 1).unwrap_or(0);

        // 每分鐘限制 60 次
        if count > 60 {
            telemetry::metric_inc(
                "rate_limit.exceeded",
                1.0,
                &[("ip".into(), req.client_ip.clone())],
            );
            return FilterAction::Reject {
                status: 429,
                message: format!("Rate limit exceeded: {}/60", count),
            };
        }

        FilterAction::Continue
    }

    fn on_response(resp: HttpResponse) -> FilterAction {
        // 把 rate limit info 加到 response header
        let mut headers = resp.headers;
        headers.push(("X-RateLimit-Limit".into(), "60".into()));
        FilterAction::ContinueResponse(HttpResponse { headers, ..resp })
    }
}

常見坑與建議

陷阱 1 · Wasmtime async Wasmtime 的 async 支援需要 Tokio executor + Config::async_support(true)。不要混用 sync 與 async API。
陷阱 2 · Component instance 狀態 Reuse component instance 時，要記得 reset state——尤其是 component 內可能有 lazy_static 全域變數。建議在 WIT 介面中加一個 reset() export，由 pool 在 put 時呼叫。
陷阱 3 · Trace context propagation Wasm component 拿不到 Tokio thread-local。一定要在 invoke 前把 trace context 顯式塞進 component 的 Store data，由 host import 函式查詢。
陷阱 4 · fuel 不夠細 Wasmtime fuel 是「每條指令扣 1」。複雜 component 用幾百萬 fuel 算正常。設太低會造成正常請求 trap，要實測 profile。

  • 貢獻上游：到 Wasmtime / Spin / wasmCloud 等專案找 good-first-issue 開始貢獻
  • 標準參與：加入 W3C WebAssembly Community Group、WASI Subgroup 的會議與郵件群

職涯路徑

Wasm 工程師在 2026 年仍屬稀缺人才。完成這個 Capstone 後，你可以瞄準：

  • 邊緣運算平台：Cloudflare、Fastly、Akamai、Vercel、Fermyon
  • 雲端原生工具：Bytecode Alliance 成員（Microsoft、AWS、Google、Intel、Red Hat 等）
  • Service Mesh / API Gateway 公司：Tetrate、Solo.io、Kong、APISIX
  • 應用層：任何需要外掛系統的 SaaS、enterprise application

CLOSING結語

你從 M01 的「Wasm 是什麼」走到了 Capstone 的「我自己設計 Wasm 平台」。這段旅程不只是學會 Wasm 的技術細節，更是建立對「可攜、可組合、能力導向」這套新範式的直覺。

2026 年是 Wasm 從「實驗」走向「主流」的關鍵年。Component Model 1.0、SpinKube 進 CNCF、WASIp3 RC、Fermyon 被 Akamai 收購、Spin / wasmCloud 進入企業生產——這些都意味著未來幾年的雲原生圖景會被重新畫過。

本 Handbook 涵蓋的內容會隨生態演進需要更新。建議定期回看 webassembly.org/features/、bytecodealliance.org/articles、CNCF blog 等資源，每季度為自己做一次知識補完。

如果你完成了 Capstone、發了 blog、給團隊做了 demo——也歡迎把成果分享出來。Wasm 社群還在初期，每一個踏實的實作都是一個重要貢獻。
