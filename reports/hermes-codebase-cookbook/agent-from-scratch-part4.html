System Prompt 工程

agent 的 system prompt 不是一句話，而是一個包含 10 個層次的精確結構。 每一層的順序和字元上限都有工程原因，核心是讓 Anthropic prompt cache 命中率最大化。

Part 4 · Prompt Assembly

為何 System Prompt 要固定

在 Part 1 我們只用一句固定字串作為 system prompt。這沒有問題——但隱藏著一個關鍵工程決策：system prompt 在 session 開始後必須保持穩定，不隨對話變化。

Prompt Cache 的工作原理

Anthropic 的 prompt caching 把 system prompt 的 prefix hash 起來。當下一次請求的 prefix 和上次完全一樣（包括所有空白和換行），Anthropic 直接回傳快取的 KV pairs，不重新計算。快取命中的 token 費用只有正常費用的 10%。

情境Prefix 穩定度Cache 命中率費用（Anthropic input）
system prompt 完全固定100%~95%$0.03/MTok（cache read）
session 中途插入記憶更新破壞0%$0.30/MTok（full price）
每次加時間戳到 prefix0%0%$0.30/MTok（full price）

這解釋了兩個設計決策：

  • Frozen Snapshot：MEMORY.md 在 session 開始時快照一次，整個 session 不再更新到 system prompt（下個 session 才生效）
  • 時間戳放最後：timestamp 放在 Layer 9，遠離 Layer 1-8 的穩定 prefix，避免破壞 cache
設計決策日誌 #006

決策：system prompt 分為「cached layers」（1-8）和「ephemeral layers」（9-10）兩大類。
理由：cached layers 在 session 開始時固定；ephemeral layers 每次 API call 時動態注入（budget warnings、context pressure 等）。Anthropic cache 只快取前面的穩定部分。
Hermes 原文："Hermes deliberately separates cached system prompt state from ephemeral API-call-time additions. This is one of the most important design choices in the project."

十層架構的設計邏輯

LLM 的注意力有前置偏向（primacy bias）——越早出現的內容權重越高。以下是完整的 10 層順序，對應 Hermes prompt_builder.py 的組裝邏輯：

1
Agent Identity Cached
SOUL.md 或 DEFAULT_AGENT_IDENTITY · 上限 20,000 chars · Cache 的 anchor
2
Tool-aware Guidance Cached
記憶工具使用指引、session_search 使用時機
3
Honcho Static Block Cached
Honcho memory provider 的靜態 context（若啟用）
4
Optional System Message Cached
config 或 API 傳入的自訂 system message override
5
Frozen MEMORY.md Snapshot Cached
~/.myagent/memories/MEMORY.md · Session 開始時快照 · 上限 2,200 chars
6
Frozen USER.md Snapshot Cached
~/.myagent/memories/USER.md · Session 開始時快照 · 上限 1,375 chars
7
Skills Index（Level 0）Cached
所有 skill 的名稱 + 一句描述 · 約 3K tokens · Progressive Disclosure
8
Context Files Cached
.hermes.md → AGENTS.md → CLAUDE.md → .cursorrules（第一個匹配）
9
Timestamp + Session ID Ephemeral
當前時間、session ID · 每次 API call 重新生成 · 不影響 cache
10
Platform Hint Ephemeral
"You are a CLI AI Agent..." · Budget warnings · Context pressure
💡 快取分界點
Layers 1-8 是穩定的 cached prefix，Anthropic 快取分界點打在 Layer 8 結尾。Layers 9-10 每次重新生成，不影響快取穩定性。即使每分鐘呼叫一次，Layer 1-8 永遠命中快取。

Layer 1：SOUL.md — Agent 身份定義

SOUL.md 是 agent 的第一層、最高優先的身份定義，也是整個 prompt cache 的 anchor。

markdown~/.myagent/SOUL.md（範例）
You are Alex, a senior software engineer and researcher.

## Core Traits
- Precise and direct in communication
- Prefers working code over lengthy explanations
- Admits uncertainty rather than fabricating answers
- Checks existing context before asking the user to repeat themselves

## Working Style
- Runs tests before declaring a fix complete
- Uses session_search when the user references past work
- Documents non-obvious decisions, not obvious ones
pythonagent/prompt_builder.py — load_soul_md()
from pathlib import Path
import os

DEFAULT_AGENT_IDENTITY = """You are a helpful AI agent.
You are helpful, knowledgeable, and direct.
Be targeted and efficient. Admit uncertainty when appropriate."""

SOUL_MAX_CHARS = 20_000


def get_agent_home() -> Path:
    home = os.environ.get("MYAGENT_HOME")
    return Path(home) if home else Path.home() / ".myagent"


def load_soul_md() -> str:
    """載入 SOUL.md，若不存在則回傳預設身份。"""
    soul_path = get_agent_home() / "SOUL.md"
    if not soul_path.exists():
        return DEFAULT_AGENT_IDENTITY
    content = soul_path.read_text(encoding="utf-8").strip()
    if len(content) > SOUL_MAX_CHARS:
        content = content[:SOUL_MAX_CHARS] + "\n[SOUL.md truncated at 20,000 chars]"
    return content

Layer 5-6：記憶 Snapshot（Frozen）

MEMORY.md 和 USER.md 在 session 開始時各讀一次，快照後整個 session 不再變動。字元上限嚴格限制，避免記憶膨脹。

檔案用途字元上限約 tokens
MEMORY.md環境事實、工具怪癖、慣例、學到的技巧2,200~600
USER.md使用者姓名、角色、溝通偏好、技術水平1,375~380
pythonagent/prompt_builder.py — Layer 5-6
MEMORY_MAX_CHARS = 2_200
USER_MAX_CHARS   = 1_375


def _load_bounded_file(path: Path, max_chars: int, label: str) -> str | None:
    if not path.exists():
        return None
    content = path.read_text(encoding="utf-8").strip()
    if not content:
        return None
    if len(content) > max_chars:
        content = content[:max_chars] + f"\n[{label} truncated]"
    return content


def load_memory_snapshot() -> tuple[str | None, str | None]:
    """
    Session 開始時呼叫一次，回傳 (memory_text, user_text)。
    這個 snapshot 整個 session 期間固定，不再重讀磁碟。
    即使 agent 在 session 中修改 MEMORY.md，也要下個 session 才生效。
    """
    memories_dir = get_agent_home() / "memories"
    memories_dir.mkdir(parents=True, exist_ok=True)
    memory = _load_bounded_file(memories_dir / "MEMORY.md", MEMORY_MAX_CHARS, "MEMORY")
    user   = _load_bounded_file(memories_dir / "USER.md",   USER_MAX_CHARS,   "USER")
    return memory, user


def _format_memory_block(memory: str | None, user: str | None) -> str:
    parts = []
    if memory:
        used_pct = int(len(memory) / MEMORY_MAX_CHARS * 100)
        parts.append(
            f"== MEMORY (your personal notes) [{used_pct}% — {len(memory)}/{MEMORY_MAX_CHARS} chars] ==\n{memory}"
        )
    if user:
        parts.append(f"== USER PROFILE ==\n{user}")
    return "\n\n".join(parts)

Layer 7：Skills Index（Progressive Disclosure）

Skills 不是全文塞進 prompt。Layer 7 只放 Level-0 索引：每個 skill 的名稱和一句描述，agent 按需用 skill_view(name) 載入完整內容。

pythonagent/prompt_builder.py — build_skills_index()
import yaml

SKILLS_PREAMBLE = """## Skills (mandatory)
Before replying, scan the skills below. If one clearly matches
your task, load it with skill_view(name) and follow its instructions."""


def build_skills_index() -> str:
    """掃描 skills 目錄，建立 Level-0 索引（name + description）。"""
    skills_dir = get_agent_home() / "skills"
    if not skills_dir.exists():
        return ""

    entries: list[dict] = []
    for skill_dir in sorted(skills_dir.iterdir()):
        skill_file = skill_dir / "SKILL.md"
        if not skill_file.exists():
            continue
        fm = _parse_front_matter(skill_file.read_text(encoding="utf-8"))
        if not fm:
            continue
        # Platform 過濾
        platforms = fm.get("platforms")
        if platforms:
            import sys
            cur = "macos" if sys.platform == "darwin" else "windows" if sys.platform == "win32" else "linux"
            if cur not in platforms:
                continue
        category = fm.get("metadata", {}).get("hermes", {}).get("category", "general")
        entries.append({"name": fm.get("name", skill_dir.name),
                        "description": fm.get("description", ""),
                        "category": category})

    if not entries:
        return ""

    by_cat: dict[str, list] = {}
    for e in entries:
        by_cat.setdefault(e["category"], []).append(e)

    lines = [SKILLS_PREAMBLE, ""]
    for cat, skills in sorted(by_cat.items()):
        lines.append(f"  {cat}:")
        for s in skills:
            lines.append(f"    - {s['name']}: {s['description']}")
    lines.append("")
    return "\n".join(lines)


def _parse_front_matter(content: str) -> dict | None:
    if not content.startswith("---"):
        return None
    parts = content.split("---", 2)
    if len(parts) < 3:
        return None
    try:
        return yaml.safe_load(parts[1]) or {}
    except yaml.YAMLError:
        return None

Layer 8：Context Files（AGENTS.md 等）

Context files 讓不同專案有不同的 agent 行為，無需手動切換。採用第一匹配優先策略：找到一個就停止搜尋。

pythonagent/prompt_builder.py — load_context_files()
def load_context_files(cwd: Path | None = None) -> str:
    """
    優先序（第一個找到即停止）：
    1. .hermes.md / HERMES.md（向上走到 git root）
    2. AGENTS.md（只在 cwd）
    3. CLAUDE.md（只在 cwd）
    4. .cursorrules（只在 cwd）
    """
    cwd = (cwd or Path.cwd()).resolve()

    # 1. 向上搜尋 .hermes.md
    current = cwd
    while True:
        for name in (".hermes.md", "HERMES.md"):
            candidate = current / name
            if candidate.exists():
                return _fmt_ctx(name, candidate.read_text(encoding="utf-8"))
        if (current / ".git").exists() or current.parent == current:
            break
        current = current.parent

    # 2-4. 只在 cwd
    for name in ("AGENTS.md", "CLAUDE.md", ".cursorrules"):
        candidate = cwd / name
        if candidate.exists():
            return _fmt_ctx(name, candidate.read_text(encoding="utf-8"))
    return ""


def _fmt_ctx(name: str, content: str) -> str:
    if not content.strip():
        return ""
    return f"# Project Context ({name})\n{content.strip()}"

Ephemeral Layers 9-10

Ephemeral layers 在每次 API call 時重新生成，提供當前狀態資訊——時間、context 壓力、budget warnings。

pythonagent/prompt_builder.py — build_ephemeral_layers()
from datetime import datetime

_PLATFORM_HINTS = {
    "cli": "You are a CLI AI Agent. Try not to use markdown but simple text renderable inside a terminal.",
    "telegram": "You are a Telegram bot. Keep responses concise. Use telegram-compatible markdown.",
    "discord": "You are a Discord bot. Use Discord markdown. Keep responses under 2000 chars when possible.",
    "api": "You are responding via API. Use markdown formatting.",
}


def build_ephemeral_layers(
    session_id: str = "",
    platform: str = "cli",
    context_fill_pct: float = 0,
    iteration: int = 0,
    max_iterations: int = 25,
) -> str:
    """Layer 9-10：每次 API call 動態生成，不影響 cache prefix。"""
    parts = []

    # Layer 9：時間戳
    now = datetime.now().strftime("%Y-%m-%dT%H:%M:%S")
    ts_line = f"Current time: {now}"
    if session_id:
        ts_line += f" | Session: {session_id}"
    parts.append(ts_line)

    # Layer 10：Platform hint
    parts.append(_PLATFORM_HINTS.get(platform, _PLATFORM_HINTS["api"]))

    # Context 壓力警告
    if context_fill_pct >= 0.80:
        parts.append(
            f"CONTEXT {context_fill_pct:.0%} FULL — Be concise, avoid long outputs."
        )

    # Budget 警告
    remaining = max_iterations - iteration
    if remaining <= 5:
        parts.append(
            f"ITERATION BUDGET: {remaining} remaining. Wrap up; avoid unnecessary tool calls."
        )

    return "\n".join(parts)

完整 PromptBuilder

pythonagent/prompt_builder.py — PromptBuilder class（完整）
"""
agent/prompt_builder.py — 完整 PromptBuilder
組裝 10 層 system prompt，支援 Anthropic prompt cache。
包含 load_soul_md / load_memory_snapshot / build_skills_index /
load_context_files / build_ephemeral_layers（見 4.3-4.7 節）
"""
from __future__ import annotations
from dataclasses import dataclass
from pathlib import Path


_TOOL_GUIDANCE = (
    "You have persistent memory across sessions. Save durable facts using the memory tool: "
    "user preferences, environment details, tool quirks, stable conventions. "
    "When the user references past work, use session_search to recall it."
)


@dataclass
class PromptSnapshot:
    """Session 開始時建立一次，整個 session 期間固定。"""
    identity: str
    tool_guidance: str
    memory: str | None
    user_profile: str | None
    skills_index: str
    context_files: str


@dataclass
class BuildResult:
    """build() 的回傳值。"""
    cached_prefix: str   # Layers 1-8，穩定，用於 prompt cache
    full_prompt: str      # Layers 1-10，每次 API call 使用
    char_count: int
    has_memory: bool
    has_skills: bool
    has_context_files: bool


class PromptBuilder:
    """
    管理 system prompt 的組裝。
    每個 AIAgent session 建立一個 PromptBuilder instance。
    session 開始時呼叫 snapshot()，之後每次 API call 呼叫 build()。
    """

    def __init__(
        self,
        cwd: Path | None = None,
        extra_system_prompt: str = "",
    ) -> None:
        self.cwd = cwd
        self.extra = extra_system_prompt
        self._snap: PromptSnapshot | None = None

    def snapshot(self) -> None:
        """Session 開始時呼叫一次。讀取所有 cached layers 並儲存快照。"""
        memory, user = load_memory_snapshot()
        self._snap = PromptSnapshot(
            identity=load_soul_md(),
            tool_guidance=_TOOL_GUIDANCE,
            memory=memory,
            user_profile=user,
            skills_index=build_skills_index(),
            context_files=load_context_files(self.cwd),
        )

    def build(
        self,
        session_id: str = "",
        platform: str = "cli",
        context_fill_pct: float = 0,
        iteration: int = 0,
        max_iterations: int = 25,
    ) -> BuildResult:
        """每次 API call 前呼叫。Layers 1-8 來自 snapshot，Layers 9-10 動態生成。"""
        if self._snap is None:
            self.snapshot()
        s = self._snap
        parts = [s.identity, s.tool_guidance]
        if self.extra:
            parts.append(self.extra)
        mem_block = _format_memory_block(s.memory, s.user_profile)
        if mem_block:
            parts.append(mem_block)
        if s.skills_index:
            parts.append(s.skills_index)
        if s.context_files:
            parts.append(s.context_files)

        cached_prefix = "\n\n".join(p for p in parts if p)
        ephemeral = build_ephemeral_layers(
            session_id=session_id, platform=platform,
            context_fill_pct=context_fill_pct,
            iteration=iteration, max_iterations=max_iterations,
        )
        full_prompt = cached_prefix + ("\n\n" + ephemeral if ephemeral else "")
        return BuildResult(
            cached_prefix=cached_prefix,
            full_prompt=full_prompt,
            char_count=len(full_prompt),
            has_memory=bool(s.memory),
            has_skills=bool(s.skills_index),
            has_context_files=bool(s.context_files),
        )

整合進 AIAgent

pythonagent/core.py — 整合 PromptBuilder
from agent.prompt_builder import PromptBuilder

class AIAgent:
    def __init__(self, ..., cwd=None, platform="cli") -> None:
        ...
        self.platform = platform
        self._prompt_builder = PromptBuilder(cwd=cwd)
        self._prompt_builder.snapshot()  # Session 開始，一次性讀取記憶快照

    def _build_messages(self, iteration: int = 0) -> list[dict]:
        result = self._prompt_builder.build(
            session_id=self._session_id,
            platform=self.platform,
            iteration=iteration,
            max_iterations=self.max_iterations,
        )
        return [{"role": "system", "content": result.full_prompt}] + self.history
