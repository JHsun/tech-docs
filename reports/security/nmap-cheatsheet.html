Target Specification

Basic
ℹ️

可傳入 hostname、IP address、CIDR 網段、範圍等多種格式。例如：scanme.nmap.org、192.168.1.0/24、10.0.0-255.1-254

從檔案讀取目標清單

-iL

從文字檔讀取 host/網段清單，一行一個，支援大批量掃描。

nmap -iL targets.txt

隨機選取目標

-iR

隨機選取 N 個 host 進行掃描，0 表示無限循環。

nmap -iR 100 -p 80 --open

排除特定主機

--exclude

從掃描範圍中排除特定 host 或網段，逗號分隔。

nmap 192.168.1.0/24 --exclude 192.168.1.1,192.168.1.254

從檔案排除

--excludefile

從指定檔案讀取排除清單，適合長清單使用。

nmap 10.0.0.0/8 --excludefile exclude.txt

CIDR 子網段

CIDR

掃描整個 /24 子網段（256 個 host）。

nmap 192.168.1.0/24

範圍掃描

範圍

使用 dash 指定範圍，可跨 octet 使用。

nmap 192.168.1.1-254
nmap 10.0.0-5.1-254
🔍

Host Discovery

Basic

List Scan — 僅列出目標

-sL

僅列出所有指定的目標 host，不實際發送封包，用於驗證 target 清單。

nmap -sL 192.168.1.0/24

Ping Scan — 禁用 port scan

-sn

只做 host discovery，不進行 port 掃描，快速找出存活主機。

nmap -sn 192.168.1.0/24

跳過 host discovery

-Pn

把所有 host 視為在線，跳過 ping 探測。目標防火牆封鎖 ICMP 時必用。

nmap -Pn 192.168.1.100

TCP SYN / ACK Discovery

-PS -PA

發送 TCP SYN（-PS）或 ACK（-PA）到指定 port 進行 host discovery。

nmap -PS22,80,443 192.168.1.0/24
nmap -PA80 192.168.1.0/24

UDP / SCTP Discovery

-PU -PY

透過 UDP（-PU）或 SCTP（-PY）做 host discovery，繞過 TCP-only 防火牆。

nmap -PU53 10.0.0.1
nmap -PY 10.0.0.0/24

ICMP Echo / Timestamp / Netmask

-PE -PP -PM

ICMP 探測：echo request（-PE）、timestamp（-PP）、address mask（-PM）。

nmap -PE 192.168.1.1
nmap -PP -PM 10.0.0.0/24

IP Protocol Ping

-PO

發送帶有指定 IP 協議 header 的封包做探測。

nmap -PO1,2,4 192.168.1.1

Traceroute

--traceroute

追蹤每個 host 的路由路徑（hop path）。

nmap --traceroute scanme.nmap.org

DNS 控制

-n / -R

-n 永不做 DNS resolution（加速）；-R 一律做 resolution。

nmap -n 192.168.1.0/24      # 不做 DNS 查詢
nmap -R --dns-servers 8.8.8.8 10.0.0.1

Scan Techniques

Intermediate
旗標 掃描類型 需要 root？ 說明 範例
-sS TCP SYN（半開） ✅ 是 最常用；發 SYN 不完成三次握手，速度快、隱蔽性高 sudo nmap -sS 192.168.1.1
-sT TCP Connect ❌ 否 完整三次握手；無 root 時的預設，留下連線紀錄 nmap -sT 192.168.1.1
-sA TCP ACK ✅ 是 用於偵測 firewall 規則，無法判斷 open/closed，只判斷 filtered sudo nmap -sA 192.168.1.1
-sW TCP Window ✅ 是 類似 ACK，利用 TCP Window 大小判斷 port 狀態 sudo nmap -sW 192.168.1.1
-sM TCP Maimon ✅ 是 發送 FIN/ACK，利用 BSD 系統 bug 進行探測 sudo nmap -sM 192.168.1.1
-sU UDP ✅ 是 掃描 UDP port，速度慢，可搭配 -sS 同時掃描 sudo nmap -sU -sS 192.168.1.1
-sN TCP Null ✅ 是 不設任何 flag，可繞過某些 stateless 防火牆 sudo nmap -sN 192.168.1.1
-sF TCP FIN ✅ 是 只設 FIN flag，類似 Null scan 的繞牆技巧 sudo nmap -sF 192.168.1.1
-sX Xmas Scan ✅ 是 設 FIN + PSH + URG，在 RFC 對應系統上有效 sudo nmap -sX 192.168.1.1
-sI Idle / Zombie ✅ 是 借用 zombie host 的 IPID 盲掃，不暴露真實 IP sudo nmap -sI zombie_host 192.168.1.1
-sY SCTP INIT ✅ 是 SCTP 協議 INIT chunk 掃描 sudo nmap -sY 192.168.1.1
-sZ SCTP COOKIE-ECHO ✅ 是 SCTP COOKIE-ECHO 掃描，可穿透部分防火牆 sudo nmap -sZ 192.168.1.1
-sO IP Protocol ✅ 是 掃描目標支援哪些 IP 層協議（TCP, UDP, ICMP 等） sudo nmap -sO 192.168.1.1
-b FTP Bounce ❌ 否 利用 FTP 中繼伺服器進行 proxy 掃描（多數現代伺服器已修補） nmap -b ftp.relay.com 192.168.1.1
--scanflags 自訂 TCP flags ✅ 是 自訂任意 TCP flag 組合：SYN, ACK, FIN, RST, URG, PSH, ECE, CWR sudo nmap --scanflags SYNFIN 192.168.1.1

Port Specification & Scan Order

Basic

指定 port 或範圍

-p

指定單一、多個或範圍 port，可混合 TCP / UDP。

nmap -p 22              # 單一 port
nmap -p 22,80,443       # 多個
nmap -p 1-1024          # 範圍
nmap -p U:53,T:80,443   # UDP 53 + TCP 80/443
nmap -p-               # 全部 65535 port

快速模式

-F

只掃描 100 個最常見 port，速度快很多。

nmap -F 192.168.1.0/24

Top N Ports

--top-ports

掃描最常見的 N 個 port，依 nmap-services 頻率排序。

nmap --top-ports 1000 192.168.1.1

排除 port

--exclude-ports

從掃描範圍排除指定 port。

nmap -p 1-65535 --exclude-ports 9100-9200 192.168.1.1

依比率篩選 port

--port-ratio

只掃描出現頻率高於指定比率（0~1）的 port。

nmap --port-ratio 0.1 192.168.1.1

循序掃描

-r

按序掃描 port（不隨機化），方便對比分析。

nmap -r 192.168.1.1

Service / Version Detection

Intermediate

服務版本偵測

-sV

探測開放 port 上的服務與版本資訊（service banner 分析）。

nmap -sV 192.168.1.1

Version Intensity

--version-intensity

設定 probe 強度 0（輕量）到 9（全試），預設為 7。

nmap -sV --version-intensity 5 192.168.1.1
nmap -sV --version-light 192.168.1.1   # 強度 2
nmap -sV --version-all 192.168.1.1    # 強度 9

Version Trace（除錯）

--version-trace

顯示 version scan 的詳細活動，用於 debug。

nmap -sV --version-trace 192.168.1.1

OS Detection

Intermediate
⚠️

OS Detection 需要至少一個 open 和一個 closed port 才能有效偵測。

啟用 OS 偵測

-O

嘗試偵測目標作業系統（需 root 權限）。

sudo nmap -O 192.168.1.1

限制有效目標

--osscan-limit

只對具備有效開/關 port 組合的目標做 OS 偵測，節省時間。

sudo nmap -O --osscan-limit 192.168.1.0/24

積極猜測 OS

--osscan-guess

當無法確認 OS 時，更積極地列出猜測結果（含低信心比對）。

sudo nmap -O --osscan-guess 192.168.1.1

全功能掃描 -A

-A

啟用 OS detection + version detection + script scan + traceroute，一次全開。

sudo nmap -A 192.168.1.1
📜

NSE 腳本引擎（Nmap Scripting Engine）

Advanced
ℹ️

Nmap 7.96+ 內建 612 個 NSE scripts，以 Lua 撰寫。腳本分類：auth、broadcast、brute、default、discovery、dos、exploit、external、fuzzer、intrusive、malware、safe、version、vuln。

執行預設腳本

-sC

等同 --script=default，執行所有標記為 default 的安全腳本。

nmap -sC 192.168.1.1
# 等同
nmap --script=default 192.168.1.1

指定腳本或分類

--script

指定腳本名稱、分類、目錄，逗號分隔可多選。

nmap --script=http-enum 192.168.1.1
nmap --script=vuln 192.168.1.1
nmap --script=default,safe 192.168.1.1
nmap --script="http-*" 192.168.1.1

傳入腳本參數

--script-args

傳遞 key=value 參數給 NSE 腳本。

nmap --script=http-brute \
  --script-args userdb=/tmp/users.txt,passdb=/tmp/pass.txt \
  -p 80 192.168.1.1

從檔案傳腳本參數

--script-args-file

從檔案讀取 NSE 腳本參數（key=value，一行一筆）。

nmap --script=smb-brute \
  --script-args-file args.txt -p 445 192.168.1.1

顯示腳本通訊細節

--script-trace

顯示 NSE 腳本所有收發資料，用於 debug。

nmap --script=http-enum --script-trace -p 80 192.168.1.1

更新腳本資料庫

--script-updatedb

重建 script.db 索引，安裝新腳本後需執行。

sudo nmap --script-updatedb

查詢腳本說明

--script-help

顯示指定腳本的詳細說明文件。

nmap --script-help=http-enum
nmap --script-help=smb-vuln-ms17-010

常用 NSE 腳本範例

🌐 HTTP 列舉

探測 Web 服務目錄結構、robots.txt、headers

nmap --script=http-enum,http-headers,http-title \
  -sV -p 80,443,8080 192.168.1.1

🗂 SMB 漏洞偵測

偵測 EternalBlue（MS17-010）等 SMB 弱點

nmap --script=smb-vuln-ms17-010,smb-security-mode \
  -p 445 192.168.1.0/24

🔐 SSL/TLS 弱點

偵測 POODLE、BEAST、Heartbleed、弱加密套件

nmap --script=ssl-heartbleed,ssl-poodle,ssl-enum-ciphers \
  -p 443 192.168.1.1

🗃 FTP 匿名登入偵測

偵測是否允許 anonymous FTP 存取

nmap --script=ftp-anon,ftp-bounce -p 21 192.168.1.0/24

🐛 全漏洞掃描

執行所有 vuln 類別腳本（注意：可能具侵入性）

sudo nmap --script=vuln -sV 192.168.1.1

📡 DNS 列舉

嘗試 DNS zone transfer、暴力列舉 subdomain

nmap --script=dns-zone-transfer,dns-brute \
  -p 53 ns.example.com

Timing & Performance

Intermediate
Template名稱說明適用場景
-T0Paranoid5 分鐘間隔，序列化探測，極慢IDS 繞過，高度隱蔽
-T1Sneaky15 秒間隔繞過大多數 IDS
-T2Polite減少頻寬、資源消耗不影響目標系統
-T3Normal預設值，平衡速度與可靠性一般掃描
-T4Aggressive快速掃描，適合快速網路內網、授權滲透測試
-T5Insane極速，可能漏掉 port 或崩潰目標CTF、測試環境

主機群組大小

--min/max-hostgroup

控制同時掃描多少主機（平行化）。

nmap --min-hostgroup 10 --max-hostgroup 50 192.168.1.0/24

Probe 平行化

--min/max-parallelism

控制同時發送的 probe 數量。

nmap --min-parallelism 50 --max-parallelism 200 192.168.1.1

RTT Timeout 控制

--min/max/initial-rtt-timeout

設定 Round Trip Time 的最小、最大、初始 timeout（支援 ms / s / m / h 單位）。

nmap --max-rtt-timeout 500ms --initial-rtt-timeout 200ms 192.168.1.1

最大重試次數

--max-retries

設定 port scan probe 的最大重送次數，降低可加速。

nmap --max-retries 2 192.168.1.0/24

Host Timeout

--host-timeout

放棄回應過慢目標的最長等待時間。

nmap --host-timeout 30m 192.168.1.0/24

Probe 間隔

--scan-delay

設定每個 probe 之間的延遲，降低被偵測的機率。

nmap --scan-delay 1s 192.168.1.1
nmap --max-scan-delay 5s 192.168.1.0/24

速率控制

--min/max-rate

控制每秒發送封包的最低與最高速率。

nmap --min-rate 1000 192.168.1.0/24   # 至少 1000 pps
nmap --max-rate 500 192.168.1.0/24    # 最多 500 pps

Firewall / IDS Evasion & Spoofing

Advanced
🚨

以下技術僅限在合法授權環境使用。未授權的掃描與欺騙行為可能觸犯法律。

封包分片

-f

將 TCP header 分散到多個小封包，繞過簡易封包過濾。-f -f 使用 16 byte fragment。

sudo nmap -f 192.168.1.1
sudo nmap --mtu 24 192.168.1.1   # 自訂 MTU（需為 8 的倍數）

Decoy 誘餌偽裝

-D

使用多個誘餌 IP，讓目標難以判斷真實掃描來源，ME 代表自己。

sudo nmap -D 10.0.0.1,10.0.0.2,ME 192.168.1.1
sudo nmap -D RND:5 192.168.1.1  # 隨機5個誘餌

偽造來源 IP

-S

偽造封包來源 IP（需在同網段或能路由，否則收不到回應）。

sudo nmap -S 192.168.1.200 -e eth0 192.168.1.1

指定網路介面

-e

指定用哪個網路介面發送封包。

sudo nmap -e eth0 192.168.1.1
sudo nmap -e tun0 10.10.10.1  # VPN 介面

偽造來源 Port

-g / --source-port

使用指定 source port，某些防火牆信任特定 port（如 53/DNS）。

sudo nmap -g 53 192.168.1.1
sudo nmap --source-port 88 192.168.1.1

HTTP / SOCKS4 Proxy

--proxies

透過 HTTP 或 SOCKS4 proxy 中繼 TCP 連線。

nmap --proxies http://proxy:8080 192.168.1.1
nmap --proxies socks4://127.0.0.1:9050 192.168.1.1

偽造 MAC 地址

--spoof-mac

偽造 MAC（可用 0 隨機、廠商名稱、完整 MAC）。

sudo nmap --spoof-mac Apple 192.168.1.1
sudo nmap --spoof-mac 0 192.168.1.1   # 完全隨機

自訂 TTL

--ttl

設定封包的 IP TTL 值。

sudo nmap --ttl 64 192.168.1.1

附加隨機資料

--data-length

在封包中附加隨機 padding bytes，改變封包特徵。

sudo nmap --data-length 50 192.168.1.1

錯誤 Checksum

--badsum

發送帶有錯誤 checksum 的封包，測試防火牆行為。

sudo nmap --badsum 192.168.1.1

Output 格式

Basic

一般文字輸出

-oN

儲存為人類可讀的 normal 格式（.nmap 慣用）。

nmap -oN scan.nmap 192.168.1.1

XML 輸出

-oX

機器可讀的 XML，可匯入 Metasploit、報告工具等。

nmap -oX scan.xml 192.168.1.1

Grepable 輸出

-oG

適合 grep / awk 快速解析的格式。

nmap -oG scan.gnmap 192.168.1.1

三格式同時輸出

-oA

同時產生 .nmap、.xml、.gnmap 三個檔案，最推薦的儲存方式。

nmap -oA scan_results 192.168.1.1
# 產生 scan_results.nmap / .xml / .gnmap

增加詳細程度

-v / -vv

提高輸出詳細程度，可用多個 -v 疊加。

nmap -v 192.168.1.1
nmap -vvv 192.168.1.1  # 更詳細

除錯模式

-d / -dd

顯示 debug 訊息，多個 -d 增加除錯層級。

nmap -d 192.168.1.1
nmap -d2 192.168.1.1

顯示 port 狀態原因

--reason

顯示每個 port 被判定為該狀態的原因（如 syn-ack、reset）。

nmap --reason 192.168.1.1

只顯示開放 port

--open

只顯示 open 或 open|filtered 狀態的 port，過濾雜訊。

nmap --open 192.168.1.0/24

封包追蹤

--packet-trace

顯示所有發出與收到的封包詳細資訊。

nmap --packet-trace 192.168.1.1

追加輸出（不覆蓋）

--append-output

追加結果到已存在的輸出檔案，而非覆蓋。

nmap -oN all_scans.nmap --append-output 192.168.1.5

Resume 中斷掃描

--resume

從中斷的 normal 或 grepable 輸出檔案繼續掃描。

nmap --resume scan.nmap

列出介面與路由

--iflist

顯示主機的網路介面與路由表（除錯用）。

nmap --iflist

MISC 雜項

Basic

IPv6 掃描

-6

啟用 IPv6 掃描。注意 IPv6 host 無法用 ARP 探測，需指定介面。

nmap -6 ::1
nmap -6 fe80::1%eth0

版本資訊

-V

顯示 Nmap 版本號。

nmap -V

說明頁面

-h

顯示 Nmap 選項摘要說明。

nmap -h

使用 raw ethernet / IP

--send-eth / --send-ip

強制使用 raw ethernet frame 或 IP packet 發送。

sudo nmap --send-eth 192.168.1.1
sudo nmap --send-ip 192.168.1.1

自訂資料目錄

--datadir

指定 Nmap 資料檔案（nmap-services 等）的自訂目錄。

nmap --datadir /custom/nmap-data 192.168.1.1

特權 / 非特權模式

--privileged / --unprivileged

強制 Nmap 認為使用者擁有或不擁有 raw socket 權限。

nmap --privileged 192.168.1.1
nmap --unprivileged 192.168.1.1

Port 狀態說明

Basic
open
開放

服務正在該 port 監聽並接受連線，是主要關注目標。

closed
關閉

Port 可達但無服務監聽，回傳 TCP RST。主機存活的依據。

filtered
被過濾

防火牆或封包過濾器阻擋 probe，Nmap 無法判斷 open/closed。

unfiltered
未過濾

Port 可達但無法判斷 open/closed，常出現於 ACK scan。

open|filtered
開放或被過濾

無法判斷是 open 還是 filtered，常見於 UDP / IP scan 無回應時。

closed|filtered
關閉或被過濾

Idle scan 中無法確定是 closed 還是 filtered。

實戰組合指令

Advanced

🏠 內網快速存活偵測

快速找出整個 /24 子網中的存活主機（不做 port scan）

sudo nmap -sn -T4 192.168.1.0/24

🔐 完整服務指紋

版本偵測 + OS + 預設腳本，適合授權滲透測試初始列舉

sudo nmap -sV -sC -O -T4 -oA full_scan 192.168.1.1

🌐 Web 服務探測

針對常見 Web port 做服務版本 + HTTP 列舉腳本

nmap -sV --script=http-enum,http-title,http-headers \
  -p 80,443,8080,8443,8888 192.168.1.1

🔒 UDP 關鍵服務偵測

同時掃描 TCP SYN + UDP 常見服務 port

sudo nmap -sS -sU -sV \
  -p T:21,22,23,25,80,443,U:53,67,69,123,161 \
  192.168.1.0/24

🕵️ 隱蔽慢速掃描

低速、分片、誘餌，降低被 IDS 偵測的機率

sudo nmap -sS -f -T1 -D RND:5 \
  --data-length 30 --spoof-mac 0 \
  -p 22,80,443 192.168.1.1

📡 全 port + 高速

掃描全部 65535 個 port，搭配速率加速（授權環境）

sudo nmap -p- --min-rate 5000 -T4 \
  -oA allports 192.168.1.1

🗃 SMB 全面稽核

SMB 版本 + 安全模式 + 分享列舉 + 弱點偵測

sudo nmap --script=smb-vuln-ms17-010,smb-security-mode,\
smb-enum-shares,smb-enum-users \
  -sV -p 445,139 192.168.1.0/24

🌍 防火牆 ACK 偵測

用 ACK scan 判斷哪些 port 被防火牆 filtered

sudo nmap -sA -p 0-1024 --reason 192.168.1.1

NSE 腳本分類架構

mindmap
  root((NSE Scripts))
    safe
      預設安全無副作用
    default
      -sC 自動執行
      通用服務探測
    discovery
      服務與主機發現
      dns-brute
      snmp-info
    version
      輔助 -sV 版本偵測
    auth
      認證繞過測試
      匿名登入偵測
    brute
      密碼暴力破解
      http-brute
      smb-brute
    vuln
      已知弱點偵測
      ms17-010
      ssl-heartbleed
    exploit
      漏洞利用
      高風險謹慎使用
    intrusive
      侵入性操作
      可能影響目標系統

      拒絕服務測試
