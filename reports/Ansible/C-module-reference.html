附錄 C — 模組速查

附錄 A 是名稱速查（一個 module 一行）；本附錄是 cookbook——每個 module 附完整可跑範例 + 關鍵參數說明。十大主題：① 檔案；② 套件管理；③ 使用者 / 群組 / SSH key；④ 服務管理；⑤ 命令執行；⑥ 網路 / HTTP / git；⑦ 容器（Docker + Podman）；⑧ Kubernetes；⑨ 三大雲（AWS / Azure / GCP）；⑩ 常用 community（PostgreSQL / MySQL / firewalld / cron）。每個 module 名標 FQCN。範例可直接 copy paste 改參數使用。

Cookbook 用 — 200+ module 完整範例

C.1檔案系統

C.1.1copy

yaml · ansible.builtin.copy — 從本機複製到遠端 
- name: 複製檔案 + 設權限
  ansible.builtin.copy:
    src: files/app.conf
    dest: /etc/app/app.conf
    owner: app
    group: app
    mode: "0640"
    backup: true           # 改前自動備份
    validate: "sshd -t -f %s"  # 用命令驗證後才寫

- name: 直接寫內容（不從檔案）
  ansible.builtin.copy:
    content: "hello world\n"
    dest: /tmp/hello.txt

- name: 複製整個目錄
  ansible.builtin.copy:
    src: files/configs/          # 結尾 / 表示「裡面內容」
    dest: /etc/app/configs/

C.1.2template

yaml · ansible.builtin.template — Jinja2 渲染 
- name: 部署 nginx config
  ansible.builtin.template:
    src: templates/nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    mode: "0644"
    validate: "nginx -t -c %s"     # 寫前先 test
    backup: true
  notify: restart nginx

C.1.3file

yaml · ansible.builtin.file — 屬性 / 建立 / 刪除 
# 建目錄
- ansible.builtin.file:
    path: /var/log/myapp
    state: directory
    owner: myapp
    group: myapp
    mode: "0750"

# 刪除
- ansible.builtin.file:
    path: /tmp/old.lock
    state: absent

# 建 symlink
- ansible.builtin.file:
    src: /opt/myapp/current
    dest: /usr/local/bin/myapp
    state: link

# 確保只改 owner / mode（不動內容）
- ansible.builtin.file:
    path: /etc/app/secret.key
    owner: app
    mode: "0600"
    state: file

C.1.4lineinfile / blockinfile / replace

yaml · 三個編輯模組 
# lineinfile — 改 / 加單行
- ansible.builtin.lineinfile:
    path: /etc/ssh/sshd_config
    regexp: "^#?PasswordAuthentication"
    line: "PasswordAuthentication no"
    validate: "sshd -t -f %s"
  notify: restart sshd

# blockinfile — 加整段（含 marker）
- ansible.builtin.blockinfile:
    path: /etc/hosts
    block: |
      10.0.0.1 web-01
      10.0.0.2 web-02
      10.0.0.3 db-01
    marker: "# {mark} ANSIBLE MANAGED HOSTS"

# replace — regex 全檔替換（沒匹配也不報錯）
- ansible.builtin.replace:
    path: /etc/app/config.yml
    regexp: '^(\s*)version:\s*.*$'
    replace: '\1version: "{{ app_version }}"'

C.1.5unarchive / find / stat / slurp

yaml · 檔案讀取與整理 
# unarchive — 解壓（從本機 src 或遠端 URL）
- ansible.builtin.unarchive:
    src: "https://example.com/app-v1.0.tar.gz"
    dest: /opt/myapp
    remote_src: true           # 從遠端 URL 拉
    creates: /opt/myapp/bin      # 已存在就跳過（idempotent）

# find — 找檔（類 find 命令）
- ansible.builtin.find:
    paths: /var/log
    patterns: "*.log"
    age: "30d"
    size: "10m"
  register: old_logs

- ansible.builtin.file:
    path: "{{ item.path }}"
    state: absent
  loop: "{{ old_logs.files }}"

# stat — 查檔屬性
- ansible.builtin.stat:
    path: /etc/app/done.flag
  register: flag

- ansible.builtin.debug:
    msg: "已部署"
  when: flag.stat.exists

# slurp — 讀檔內容（base64）
- ansible.builtin.slurp:
    src: /etc/app/version.txt
  register: v

- ansible.builtin.debug:
    msg: "version: {{ v.content | b64decode | trim }}"

C.2.2Debian / Ubuntu — apt

yaml · ansible.builtin.apt 
# 先 update cache 再裝
- ansible.builtin.apt:
    name: nginx=1.24.*           # 鎖版本
    state: present
    update_cache: true
    cache_valid_time: 3600     # 1 小時內不重 update

# 加 repository
- ansible.builtin.apt_repository:
    repo: "deb https://download.docker.com/linux/ubuntu jammy stable"
    filename: docker
    state: present

# 加 GPG key
- ansible.builtin.apt_key:
    url: https://download.docker.com/linux/ubuntu/gpg
    state: present

# 移除 + autoremove
- ansible.builtin.apt:
    name: apache2
    state: absent
    autoremove: true
    purge: true

C.3使用者 / 群組 / SSH key

yaml · user / group / authorized_key 
# 建群組
- ansible.builtin.group:
    name: deploy
    gid: 3000
    state: present

# 建使用者
- ansible.builtin.user:
    name: deploy
    uid: 3000
    group: deploy
    groups: sudo,docker      # 額外的 group
    append: true             # 不洗掉既有 group
    shell: /bin/bash
    create_home: true
    password: "{{ 'mypass' | password_hash('sha512') }}"
    update_password: on_create     # 只新建時設密碼
    ssh_key_type: ed25519
    generate_ssh_key: true     # 自動生 SSH key

# 加 SSH authorized key
- ansible.posix.authorized_key:
    user: deploy
    key: "{{ lookup('file', 'files/deploy_id_ed25519.pub') }}"
    state: present

# 從 GitHub 拉 SSH key
- ansible.posix.authorized_key:
    user: deploy
    key: "https://github.com/USERNAME.keys"
    exclusive: true          # 移除其他 key

# sudoers — 用 lineinfile 寫 /etc/sudoers.d/
- ansible.builtin.copy:
    dest: /etc/sudoers.d/deploy
    content: "deploy ALL=(ALL) NOPASSWD: ALL\n"
    mode: "0440"
    validate: "visudo -cf %s"

C.4服務管理

yaml · systemd / service / cron 
# systemd — modern Linux 主流
- ansible.builtin.systemd:
    name: nginx
    state: started          # started / stopped / restarted / reloaded
    enabled: true
    daemon_reload: true      # 改了 unit 檔要 reload

# 部署 systemd unit + 啟動
- ansible.builtin.template:
    src: templates/myapp.service.j2
    dest: /etc/systemd/system/myapp.service
  notify: restart myapp

- ansible.builtin.systemd:
    name: myapp
    state: started
    enabled: true
    daemon_reload: true

# 跨 OS 通用 service（包含舊系統）
- ansible.builtin.service:
    name: sshd
    state: restarted

# cron — 排程
- ansible.builtin.cron:
    name: "backup logs"
    user: root
    minute: "0"
    hour: "3"
    job: "/usr/local/bin/backup.sh"

# systemd timer（推薦取代 cron）
- ansible.builtin.copy:
    dest: /etc/systemd/system/backup.timer
    content: |
      [Unit]
      Description=Daily backup
      [Timer]
      OnCalendar=daily
      Persistent=true
      [Install]
      WantedBy=timers.target

- ansible.builtin.systemd:
    name: backup.timer
    state: started
    enabled: true
    daemon_reload: true

C.5命令執行

yaml · command / shell / script / raw 
# command — 沒 shell features（最安全）
- ansible.builtin.command:
    cmd: /usr/local/bin/migrate-db --version
    creates: /var/lib/myapp/db-migrated      # 已建檔就跳過（idempotent）
  register: migrate
  changed_when: migrate.rc != 0

# shell — 有 pipe / redirect 用（次選）
- ansible.builtin.shell:
    cmd: "ps aux | grep nginx | wc -l"
  register: nginx_count
  changed_when: false      # 純查詢、不算 change

# script — 把本機 script 傳遠端跑
- ansible.builtin.script:
    cmd: files/setup-app.sh "{{ env }}"
    creates: /var/lib/myapp/setup.done

# raw — 不經 Python interpreter（裸機沒 Python 用）
- ansible.builtin.raw: apt-get install -y python3

# expect — 自動回 prompt
- ansible.builtin.expect:
    command: /usr/local/bin/initial-setup
    responses:
      "Continue?": "yes"
      "(?i)password": "{{ vault_setup_password }}"
    timeout: 300

C.6網路 / HTTP / Git

yaml · uri / get_url / git / wait_for 
# uri — REST API 呼叫
- ansible.builtin.uri:
    url: "https://api.example.com/v1/deploy"
    method: POST
    headers:
      Authorization: "Bearer {{ api_token }}"
      Content-Type: application/json
    body_format: json
    body:
      version: "{{ release_version }}"
      env: "{{ env }}"
    status_code: [200, 201]
    return_content: true
  register: deploy_resp

# 健康檢查 retry
- ansible.builtin.uri:
    url: "http://{{ inventory_hostname }}:8080/health"
    status_code: 200
  register: health
  retries: 10
  delay: 3
  until: health.status == 200

# get_url — 下載檔案
- ansible.builtin.get_url:
    url: "https://github.com/cli/cli/releases/download/v2.40.0/gh_2.40.0_linux_amd64.tar.gz"
    dest: /tmp/gh.tar.gz
    checksum: "sha256:abc123..."
    mode: "0644"

# git — clone / pull
- ansible.builtin.git:
    repo: "https://github.com/myorg/myapp.git"
    dest: /opt/myapp
    version: "v1.2.3"           # tag / branch / commit
    force: true
    accept_hostkey: true

# wait_for — 等 port / 檔案 / regex
- ansible.builtin.wait_for:
    host: "{{ ansible_host }}"
    port: 22
    timeout: 300

- ansible.builtin.wait_for:
    path: /var/lib/myapp/ready.flag
    timeout: 120

# wait_for_connection — 等遠端 SSH 可用（重啟後）
- ansible.builtin.reboot:
    reboot_timeout: 600

C.7容器（Docker + Podman）

C.7.1community.docker

yaml · docker_container / docker_image / docker_network 
# 啟 container
- community.docker.docker_container:
    name: webapp
    image: "myorg/webapp:v1.2.3"
    state: started
    restart_policy: always
    ports:
      - "8080:8080"
    env:
      DATABASE_URL: "{{ db_url }}"

    volumes:
      - /var/lib/webapp:/data
    networks:
      - name: webnet
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      retries: 3

# 拉 image / 推 image
- community.docker.docker_image:
    name: "myorg/webapp"
    tag: v1.2.3
    source: pull

- community.docker.docker_image:
    name: "registry.example.com/myorg/webapp:v1.2.3"
    push: true
    source: local

# 建 network
- community.docker.docker_network:
    name: webnet
    driver: bridge
    ipam_config:
      - subnet: "172.30.0.0/24"

yaml · podman_container 與 docker_container 幾乎同 API

C.8Kubernetes

yaml · kubernetes.core.k8s — 通用資源 
# 從 inline YAML 建任何 K8s 資源
- kubernetes.core.k8s:
    state: present
    definition:
      apiVersion: v1
      kind: Namespace
      metadata:
        name: myapp

# 從外部 yaml 檔
- kubernetes.core.k8s:
    state: present
    src: manifests/deployment.yaml

# 直接寫 Deployment
- kubernetes.core.k8s:
    definition:
      apiVersion: apps/v1
      kind: Deployment
      metadata:
        name: webapp
        namespace: myapp
      spec:
        replicas: 3
        selector:
          matchLabels: { app: webapp }
        template:
          metadata:
            labels: { app: webapp }
          spec:
            containers:
              - name: webapp
                image: "myorg/webapp:{{ release_version }}"
                ports:
                  - containerPort: 8080

# k8s_info — 查資源
- kubernetes.core.k8s_info:
    kind: Pod
    namespace: myapp
    label_selectors:
      - app=webapp
  register: pods

# Helm chart
- kubernetes.core.helm:
    name: prometheus
    chart_ref: prometheus-community/kube-prometheus-stack
    release_namespace: monitoring
    create_namespace: true
    values:
      grafana:
        enabled: true
        adminPassword: "{{ vault_grafana_pass }}"

# Wait for resource ready
- kubernetes.core.k8s:
    name: webapp
    kind: Deployment
    namespace: myapp
    wait: true
    wait_condition:
      type: Available
      status: "True"
    wait_timeout: 300

C.10常用 community（DB / firewall / 監控）

C.10.1community.postgresql / community.mysql

yaml · DB 管理常用 
# PostgreSQL — 建 DB
- community.postgresql.postgresql_db:
    name: myapp
    encoding: UTF8
    lc_collate: en_US.UTF-8
    lc_ctype: en_US.UTF-8
    template: template0
    state: present
  become_user: postgres

# 建 user + 權限
- community.postgresql.postgresql_user:
    name: appuser
    password: "{{ vault_app_db_pass }}"
    db: myapp
    priv: "ALL"
  become_user: postgres
  no_log: true

# 跑 SQL（migration / DDL）
- community.postgresql.postgresql_query:
    db: myapp
    login_user: appuser
    login_password: "{{ vault_app_db_pass }}"
    query: "SELECT count(*) FROM users"
  register: user_count

# MySQL — 同模式
- community.mysql.mysql_db:
    name: myapp
    state: present
    login_unix_socket: /var/run/mysqld/mysqld.sock

- community.mysql.mysql_user:
    name: appuser
    password: "{{ vault_mysql_pass }}"
    priv: "myapp.*:ALL"
    host: "%"

C.10.2Firewall（firewalld + ufw）

yaml · 兩種防火牆 
# firewalld（RHEL / Fedora）
- ansible.posix.firewalld:
    port: 8080/tcp
    permanent: true
    immediate: true
    state: enabled

- ansible.posix.firewalld:
    service: https
    permanent: true
    immediate: true
    state: enabled

# 來源 IP 限制
- ansible.posix.firewalld:
    rich_rule: 'rule family="ipv4" source address="10.0.0.0/8" port port="22" protocol="tcp" accept'
    permanent: true
    immediate: true
    state: enabled

# UFW（Ubuntu / Debian）
- community.general.ufw:
    rule: allow
    port: "22"
    proto: tcp
    src: 10.0.0.0/8

# 啟動 UFW（含預設 deny incoming）
- community.general.ufw:
    state: enabled
    policy: deny
    direction: incoming

C.10.3系統 / fact / 流程控制

yaml · 流程控制 + fact 操作 
# debug — 印變數 / 訊息
- ansible.builtin.debug:
    var: ansible_distribution

- ansible.builtin.debug:
    msg: "主機 {{ inventory_hostname }} 部署到 v{{ release_version }}"

# assert — 條件斷言
- ansible.builtin.assert:
    that:
      - ansible_memtotal_mb >= 1024
      - ansible_distribution_major_version | int >= 22
    fail_msg: "系統不符需求 — RAM > 1G、Ubuntu 22+"

# fail — 主動失敗
- ansible.builtin.fail:
    msg: "target_env 必填"
  when: target_env is undefined

# pause — 等待
- ansible.builtin.pause:
    seconds: 30
    prompt: "等 service 完全啟動..."

# set_fact — 動態設變數
- ansible.builtin.set_fact:
    deploy_target: "{{ 'prod' if env == 'production' else 'staging' }}"
    deploy_at: "{{ ansible_date_time.iso8601 }}"

# meta — 內建 action
- ansible.builtin.meta: flush_handlers     # 立即跑累積的 handler
- ansible.builtin.meta: clear_facts         # 清除收集的 facts
- ansible.builtin.meta: end_play             # 結束本 play

# include_role / include_tasks — 動態 include
- ansible.builtin.include_role:
    name: "deploy_{{ env }}"

- ansible.builtin.include_tasks: "tasks/{{ ansible_distribution }}.yml"
