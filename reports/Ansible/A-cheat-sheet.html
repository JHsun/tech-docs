A.1CLI 命令速查

A.1.1ansible（ad-hoc）

bash · ansible ad-hoc 常用 
# 連線測試
$ ansible all -m ping
$ ansible web-01 -m ping -i inventory/

# 跑命令
$ ansible web -a "uptime"                          # command 模組（預設）
$ ansible web -m shell -a "ps aux | grep nginx"     # shell 模組（pipe 用）

# 用 sudo
$ ansible web -b -m apt -a "name=htop state=present"
$ ansible web -b --become-user=postgres -m shell -a "psql -c '\l'"

# 看 host 的 facts
$ ansible web-01 -m setup
$ ansible web-01 -m setup -a "filter=ansible_distribution*"

# 限制範圍
$ ansible all --limit web                       # 只 web group
$ ansible all --limit 'web:!web-staging'          # web 但排除 staging
$ ansible all --limit 'web[0:5]'                 # 前 5 個

# 認證
$ ansible all --ask-pass                        # 問 SSH 密碼
$ ansible all --ask-become-pass                 # 問 sudo 密碼
$ ansible all --private-key=~/.ssh/deploy.key

A.1.2ansible-playbook

bash · ansible-playbook 常用 
# 基本
$ ansible-playbook site.yml
$ ansible-playbook site.yml -i inventory/

# 額外變數
$ ansible-playbook site.yml -e "version=v1.2.3"
$ ansible-playbook site.yml -e @vars.yml          # 從檔案讀
$ ansible-playbook site.yml -e '{"a":1,"b":[1,2]}'  # JSON

# Dry run
$ ansible-playbook site.yml --check               # 不真做
$ ansible-playbook site.yml --check --diff        # 含檔案 diff
$ ansible-playbook site.yml --syntax-check        # 只檢語法

# 限制執行
$ ansible-playbook site.yml --tags "nginx,ssl"
$ ansible-playbook site.yml --skip-tags "slow"
$ ansible-playbook site.yml --start-at-task "Deploy"
$ ansible-playbook site.yml --step                # 每 task 互動確認
$ ansible-playbook site.yml --list-tasks          # 不執行、列 task
$ ansible-playbook site.yml --list-hosts          # 不執行、列 host

# Verbose 等級
$ ansible-playbook site.yml -v                    # task 結果
$ ansible-playbook site.yml -vv                   # + 參數
$ ansible-playbook site.yml -vvv                  # + 連線細節
$ ansible-playbook site.yml -vvvv                 # + SSH 協定

# 並行
$ ansible-playbook site.yml -f 50                 # forks=50

A.1.3ansible-vault

bash · ansible-vault 常用

$ ansible-vault encrypt secrets.yml
$ ansible-vault decrypt secrets.yml
$ ansible-vault edit secrets.yml
$ ansible-vault view secrets.yml
$ ansible-vault rekey secrets.yml                 # 換密碼

# 加密單一字串
$ ansible-vault encrypt_string "mypassword" --name "db_password"

# 多 vault id（不同 secret 不同密碼）
$ ansible-vault encrypt --vault-id prod@~/.vault-prod secrets.yml
$ ansible-playbook site.yml --vault-id prod@~/.vault-prod \
    --vault-id dev@~/.vault-dev

# 從密碼檔讀（CI 用）
$ ansible-playbook site.yml --vault-password-file ~/.vault_pass

A.2Inventory 語法速查

A.2.1INI 格式

ini · inventory/hosts 
# 單獨 host
[ungrouped]
bastion.example.com

# Group + host
[web]
web-01.example.com
web-02.example.com ansible_user=ubuntu ansible_port=2222
web-03.example.com ansible_host=10.0.0.13

# Range 語法
[db]
db-[01:05].example.com                  # db-01 到 db-05
www[a:c].example.com                    # wwwa / wwwb / wwwc

# Group vars
[web:vars]
http_port=80
ansible_user=deploy

# Group of groups
[production:children]
web
db

A.2.2YAML 格式

yaml · inventory/hosts.yml 
all:
  hosts:
    bastion.example.com:

  children:
    web:
      hosts:
        web-01.example.com:
        web-02.example.com:
          ansible_user: ubuntu
          ansible_port: 2222
      vars:
        http_port: 80

    db:
      hosts:
        db-[01:05].example.com:        # range 語法相同

    production:
      children:
        web:
        db:

A.3Playbook keyword 速查

A.3.1Play-level keyword

Keyword用途例
nameplay 名稱name: 部署 web
hosts目標 host patternhosts: web:!web-staging
become整 play 用 sudobecome: true
gather_facts是否 gather（預設 yes）gather_facts: false
varsplay 級變數vars: { app: myapp }
vars_files外部變數檔vars_files: [vars/main.yml]
vars_prompt互動問變數見正文 Ch7
strategylinear / free / debugstrategy: free
serial分批跑（rolling update）serial: 5
max_fail_percentage容許多少 % host 失敗max_fail_percentage: 30
any_errors_fatal有任何 host 失敗就停整 playany_errors_fatal: true
roles套用 role見 Ch10
pre_tasksroles 前跑常用於 fact gathering
post_tasksroles 後跑常用於 health check
handlers事件觸發 task見 Ch6
environment環境變數environment: { http_proxy: ... }

A.3.2Task-level keyword

delegate_to把 task 委派到另一 host 跑
run_once整 batch 只跑一次
check_mode強制 check / 強制不 check
diff強制顯示 / 隱藏 diff
no_log不在 log 顯示（敏感任務）
notify觸發 handler
listenhandler 監聽 group 名
debugger失敗進 debugger

A.9常見錯誤訊息對照

錯誤訊息（縮）典型原因第一招
UNREACHABLE! ssh: connect to host ... port 22: No route to host 網路 / firewall / SSH service 掛 nc -zv host 22 測 port
Permission denied (publickey,password) SSH key / user 錯 ssh -vvv user@host 手動測
Missing sudo password sudo 要密碼但沒給 加 --ask-become-pass 或 NOPASSWD
'X' is undefined 變數沒定義 用 | default('xx') 或檢查 vars 來源
The conditional check '...' failed when 條件式 Jinja2 寫錯 檢查引號 / 變數展開、用 debug 印出
FAILED! ... module_stderr: ... ImportError: No module named X 遠端 Python 缺套件 遠端裝 pip pkg、或換 EE
ERROR! couldn't resolve module/action 'X' collection 沒裝 / FQCN 寫錯 ansible-galaxy collection install + 用 FQCN
FAILED! ... Failed to lock apt for exclusive operation apt 被另一 process 鎖 等 unattended-upgrades / 加 retry
fatal: ... AttributeError: 'NoneType' has no attribute API 回 null 沒處理 register + when defined 防呆
To use the 'X' plugin you need to install Y module 需要 Python 套件 EE 內加 pip dep / 系統 pip 裝
SELinux is in enforcing mode and ... SELinux context 不允許 community.general.sefcontext 設 / audit2allow 解析
Vault format unhexlify error vault 密碼錯 / 檔損壞 確認 --vault-password-file 對
ERROR! Decryption failed vault 密碼錯 / vault id 沒對應 查 ansible-vault view 試解
The error appears to be in '...': line X, column Y YAML 語法錯 yamllint 跑、檢查縮排與引號

A.10常用 ansible.cfg 範本

ini · ansible.cfg — 通用範本 
[defaults]
# Inventory + role + collection
inventory = ./inventory
roles_path = ./roles:~/.ansible/roles
collections_path = ./collections:~/.ansible/collections

# 預設不問 host key
host_key_checking = False

# 並行
forks = 50

# Fact caching（加速）
gathering = smart
fact_caching = jsonfile
fact_caching_connection = /tmp/ansible-facts
fact_caching_timeout = 86400

# Output
stdout_callback = yaml
callbacks_enabled = profile_tasks, timer

# Retry
retry_files_enabled = False

# Vault
vault_password_file = ~/.vault_pass


[ssh_connection]
# Pipelining 加速（要求 sudo NOT requiretty）
pipelining = True

# SSH 重用連線（極大加速）
ssh_args = -o ControlMaster=auto -o ControlPersist=60s -o PreferredAuthentications=publickey

# Retry
retries = 3


[privilege_escalation]
become = False             # 預設不開、playbook 內個別開
become_method = sudo
become_user = root
become_ask_pass = False


[galaxy]
server_list = automation_hub, release_galaxy

[galaxy_server.automation_hub]
url = https://hub.example.com/api/galaxy/content/published/
token = $AH_TOKEN

[galaxy_server.release_galaxy]
url = https://galaxy.ansible.com/
