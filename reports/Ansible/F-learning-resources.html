附錄 F — 推薦學習資源

本書是地圖不是百科。要繼續深入需要長期資源累積。本附錄整理2026 年最值得追蹤的 Ansible 資源——按媒介 + 主題 + 學習階段三維分類。十大區塊：① 官方資源——docs / forum / Matrix / GitHub 必訂；② 推薦書籍——按階段分（初學 / 中階 / 高階 / 專題）；③ 影片頻道——免費 + 高品質；④ Podcast——通勤學習；⑤ 付費線上課程——Udemy / Pluralsight / A Cloud Guru / KodeKloud；⑥ Red Hat 認證——RH294 / EX374 / EX447 完整路徑；⑦ 主題深入資源——網路 / 雲端 / 安全 / K8s / EDA；⑧ 必 watch 的 GitHub repo——保持 ecosystem 敏感度；⑨ Conference / 社群活動；⑩ 12 個月學習計畫範本。讀完你有未來一年都用不完的 reading list。

F.1官方資源（必訂）

F.1.1三大官方入口

📖

docs.ansible.com

主站文件——最權威 source of truth。每個 module / plugin / collection 的 reference 都在這。每週至少瀏覽一次更新頁。

💬

forum.ansible.com

Discourse 平台。Q&A / 提案 / 公告 / events。新人第一個帳號該開這。必訂閱「Project Discussions」+ 你領域的 group。

⚡

chat.ansible.im

Matrix 即時通訊。#users:ansible.com 一般使用、#devel:ansible.com 開發、#community:ansible.com 社群事務。

F.2.2非 Ansible 但必讀的相關書

📕

The Phoenix Project

Gene Kim。DevOps 必讀小說。理解「為什麼自動化」比學技術重要。讀完 Ansible 的價值才看得完整。

📗

The DevOps Handbook

Phoenix Project 同作者群。把 Phoenix Project 故事抽象成方法論。

📘

Site Reliability Engineering

Google SRE 那本。用 Ansible 做 toil reduction 的理論基礎。

📙

Infrastructure as Code (2nd ed)

Kief Morris。IaC 大方向、把 Ansible 放進更大圖景（Terraform / Pulumi 等）對照。

F.11結語

📖 寫在最後

本附錄列了大概 50+ 資源。沒人能全看完——但不必。挑 2-3 個常用的、深用、其他需要時再翻就好。

最重要的不是「資源清單多長」、而是 持續動手做。讀 100 篇文章不如自己寫 10 個 playbook、做 1 個 PR、參加 1 場 meetup。Ansible 是實作學科不是記憶學科。

本書 37 章 + 6 附錄到此完整結束。
希望這份手冊能成為你長期的副駕駛——不只是一次讀完的書、而是放在桌邊的工具書。

祝你的自動化旅程持續 radically simple。
