🧠 全新模型世代（5 月–7 月）

Claude Sonnet 5 v2.1.197
  • 預設模型 — 取代 Sonnet 4.6 成為日常開發預設
  • 原生 1M context window — 不再需要額外設定
  • 促銷定價 $2/$10 per Mtok — 至 2026/8/31 止
Claude Opus 5 v2.1.219
  • 預設 Opus 旗艦 — 取代 Opus 4.8
  • 1M context、fast mode $10/$50 per Mtok
  • Opus 4.7 正式退出 fast mode
Claude Opus 4.8 v2.1.154
  • high effort 預設 — /effort xhigh 處理最難任務
  • fast mode 成本大降：2x 標準速率換 2.5x 速度
Claude Fable 5 v2.1.170
  • Mythos 級模型 — 已安全化供一般使用
  • capability 超越所有曾公開發布的模型，需 usage credits 計費
注意（v2.1.233）：Todo/task 工具（TaskCreate/Update/List、TodoWrite）不再提供於 Opus 4.8、Sonnet 5、Fable 5、Mythos 5 及更新模型；設 CLAUDE_CODE_ENABLE_TODO_TOOLS=1 可恢復。

🖥 Agent View v2.1.139

  • claude agents — 單一列表檢視所有 Claude Code session（執行中、等你輸入、已完成）
  • claude agents --json 供腳本化整合（tmux-resurrect、status bar）
  • claude --bg / ! command 把工作丟到背景 session
  • 鍵盤快捷：← 開啟、Ctrl+X 刪除、Ctrl+R 重新命名
研究預覽：Agent View 讓多工作流並行變得可視化，適合長時間任務與平行開發。

⚡ Dynamic Workflows v2.1.154

  • 大量代理編排 — 讓 Claude 建立 workflow，在背景協調數十到數百個代理
  • /workflows 檢視執行狀態
  • 觸發關鍵字 ultracode（v2.1.160 起，原 "workflow" 不再觸發）
  • workflowSizeGuideline 設定大小指引（預設 medium <15 agents）
任務拆分：大型任務拆成多階段平行執行，適合一次處理整個 repo 級別的工作。

🤖 Subagent 進化

  • 預設背景執行（v2.1.198）— 子代理在背景跑，完成後通知主代理
  • 預設 fork 繼承（v2.1.232）— subagent_type: "fork" 繼承完整對話與 prompt cache
  • 巢狀子代理深度 3（v2.1.219，原深度 1）
  • CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION 限制每 session 200 個

💬 跨 Session 訊息 v2.1.224

  • SendMessage / ListAgents — Claude Code session 可互相傳訊（macOS & Linux）
  • @ 提及其他 session（v2.1.232）— 在 prompt 輸入 @ 直接叫出另一 session 名稱
  • crossSessionInbound / dialogExpiry 設定管控傳入訊息
  • 安全：轉傳訊息不帶使用者權威，auto mode 會阻擋權限要求

🏠 Self-Hosted Runner v2.1.224

  • claude self-hosted-runner — 把自有機器/容器變成 Claude Code web、mobile、desktop session 的執行環境
  • Team & Enterprise 方案可用
  • server-supplied hooks 支援（v2.1.229）
  • Windows 需明確 --base-dir
