4. 必認識的 Provider

主流 cloud

  • hashicorp/aws：AWS 標配，超過 1,200 種 resource
  • hashicorp/azurerm：Azure 標配
  • hashicorp/google：GCP 標配
  • hashicorp/google-beta：GCP beta 功能

K8s 生態

  • hashicorp/kubernetes：管 K8s 物件
  • hashicorp/helm：Helm chart 部署
  • integrations/github：管 GitHub repo / team / branch protection

觀測與安全

  • DataDog/datadog：Datadog 監控
  • cloudflare/cloudflare：Cloudflare CDN / DNS / WAF
  • PagerDuty/pagerduty：on-call 管理
  • grafana/grafana：Grafana dashboard / alerting

Utility（無需 cloud account 也能玩）

  • hashicorp/local：本地檔案讀寫
  • hashicorp/random：產隨機值（密碼、ID 等）
  • hashicorp/null：占位 resource，配合 provisioner 用
  • hashicorp/external：執行外部腳本作 data source
  • hashicorp/http：HTTP GET data source
  • hashicorp/time：時間相關工具（rotating、sleep）
  • hashicorp/tls：產 TLS cert / key

13. 保持最新的 4 種習慣

習慣 1：訂閱 release notes

每個 OpenTofu minor release（每約 4-6 個月一次）都有重要新功能。Watch opentofu/opentofu releases 或 RSS。

習慣 2：每月看一次 RFC 進度

看 RFC issues，了解未來方向、可早期參與討論。

習慣 3：固定看部落格

把 Spacelift / env0 / Scalr 三大 TACOS 廠商的 blog 加入 RSS 或 newsletter。它們會頻繁分析新功能與最佳實踐。

習慣 4：加入社群參與

在 CNCF Slack #opentofu 頻道潛水即可學到很多。遇到問題先搜尋舊討論，沒答案再發問。回答別人問題能加深理解。

給自己訂的「6 個月檢查」

  • OpenTofu 版本是否還是新版（落後超過 2 個 minor 該升）
  • 主要 provider 是否升過大版（如 AWS 從 5.x 到 6.x）
  • 是否有用過時 pattern（如還在用 tofu refresh、tofu taint）
  • 是否該採用新功能（OpenTofu 1.7+ encryption、1.10+ OCI、1.11+ ephemeral / enabled）
  • CI/CD pipeline 是否需要更新（OIDC、Plan-Read / Apply-Write 雙 role）
