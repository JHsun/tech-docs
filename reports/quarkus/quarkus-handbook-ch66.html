附錄 B：Panache Cheat Sheet

Hibernate ORM with Panache（Active Record + Repository 模式）快速參考。常用查詢方法、分頁、@Transactional、Reactive Panache 對照。

版本 Quarkus 3.33 LTS · Panache 3.x
更新 2026-05-16

Active Record 模式

Java
@Entity
public class Product extends PanacheEntity {
    public String name;
    public BigDecimal price;
    public String category;
    // id 自動提供（Long）
}

// 使用
Product.findAll()
Product.findById(1L)
Product.find("category", "electronics")
Product.find("name like ?1 order by name", "%phone%")
Product.list("price > ?1", 100)
Product.count("category", "electronics")
Product.delete("active = false")

// 分頁
PanacheQuery<Product> q = Product.findAll();
List<Product> page = q.page(0, 20).list();
long count = q.count();

// 持久化
@Transactional
public Product create(Product p) {
    p.persist();   // INSERT（id 自動設定）
    return p;
}

Repository 模式

Java
@ApplicationScoped
public class ProductRepository implements PanacheRepository<Product> {

    public List<Product> findByCategory(String cat) {
        return list("category = ?1 order by name", cat);
    }

    public Optional<Product> findBySku(String sku) {
        return find("sku", sku).firstResultOptional();
    }
}

常用方法速查

方法說明

.page(page, size).list()分頁
