Chat Memory：對話記憶

AI 沒有天然記憶 ── 每次呼叫都是全新對話。Chat Memory 把對話歷史注入每次 prompt，讓 LLM 記住「你剛才說過」。本章涵蓋 MessageWindowChatMemory、TokenWindowChatMemory、每用戶獨立 memory、以及 JPA 持久化 ChatMemoryStore（Pod 重啟後記憶不丟）。

版本 Quarkus LangChain4j 0.24+
更新 2026-05-16

Memory 類型

類型截斷方式適合
MessageWindowChatMemory保留最近 N 條訊息最常用，簡單直接
TokenWindowChatMemory保留最近 N 個 token精確控制成本

基本設定

Java · @MemoryId 每用戶獨立 memory
// AI Service 帶 memory
@RegisterAiService(chatMemoryProviderSupplier = RegisterAiService.BeanChatMemoryProviderSupplier.class)
public interface ChatAssistant {
    @SystemMessage("You are a helpful customer service agent. Remember user preferences.")
    String chat(@UserMessage String message, @MemoryId String sessionId);
}

// ChatMemoryProvider CDI Bean
@ApplicationScoped
public class MemoryConfig {

    @Produces
    @ApplicationScoped
    ChatMemoryProvider chatMemoryProvider() {
        return memoryId -> MessageWindowChatMemory.builder()
            .id(memoryId)
            .maxMessages(20)              // 最近 20 條訊息
            .chatMemoryStore(inMemory())  // dev: 記憶體；prod: JPA
            .build();
    }
}

JPA 持久化 Memory

Java · JPA ChatMemoryStore
@Entity
public class ChatMessageEntity {
    @Id @GeneratedValue Long id;
    String sessionId;
    @Column(columnDefinition = "TEXT")
    String messageJson;   // ChatMessage 序列化成 JSON
    LocalDateTime createdAt = LocalDateTime.now();
}

@ApplicationScoped
public class JpaChatMemoryStore implements ChatMemoryStore {

    @Inject EntityManager em;

    @Override
    public List<ChatMessage> getMessages(Object memoryId) {
        return em.createQuery(
                "SELECT m FROM ChatMessageEntity m WHERE m.sessionId = :id ORDER BY m.createdAt",
                ChatMessageEntity.class)
            .setParameter("id", memoryId.toString())
            .getResultList()
            .stream()
            .map(e -> ChatMessageDeserializer.messageFromJson(e.messageJson))
            .collect(toList());
    }

    @Override
    @Transactional
    public void updateMessages(Object memoryId, List<ChatMessage> messages) {
        // 替換整個 session 的訊息（sliding window 已截斷）
        em.createQuery("DELETE FROM ChatMessageEntity WHERE sessionId = :id")
            .setParameter("id", memoryId.toString())
            .executeUpdate();
        messages.forEach(msg -> {
            var entity = new ChatMessageEntity();
            entity.sessionId = memoryId.toString();
            entity.messageJson = ChatMessageSerializer.messageToJson(msg);
            em.persist(entity);
        });
    }

    @Override
    @Transactional
    public void deleteMessages(Object memoryId) {
        em.createQuery("DELETE FROM ChatMessageEntity WHERE sessionId = :id")
            .setParameter("id", memoryId.toString())
            .executeUpdate();
    }
}

HTTP 端點整合

Java · REST endpoint with session
@Path("/chat")
public class ChatResource {

    @Inject ChatAssistant assistant;

    @POST
    @Path("/{sessionId}")
    @Produces(MediaType.TEXT_PLAIN)
    @Consumes(MediaType.TEXT_PLAIN)
    public String chat(@PathParam("sessionId") String sessionId, String message) {
        return assistant.chat(message, sessionId);
    }

    @DELETE
    @Path("/{sessionId}")
    public void clearMemory(@PathParam("sessionId") String sessionId) {
        // 清除 session 記憶
        chatMemoryProvider.get(sessionId).clear();
    }
}

本章小結

  • Chat Memory 讓每次 LLM 呼叫帶上對話歷史，實現多輪對話。
  • @MemoryId：每個用戶/session 獨立 memory，互不干擾。
  • MessageWindowChatMemory（最近 N 條）是最常用策略；TokenWindowChatMemory 精確控制成本。
  • Dev：InMemoryChatMemoryStore；Prod：JPA 持久化 ── 重啟後記憶保留。
