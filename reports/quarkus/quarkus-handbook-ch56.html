Chapter 56 · Part XII

gRPC：Protocol Buffers 與 Quarkus gRPC

REST 是人類可讀的 API；gRPC 是機器間高效通訊的首選 ── 二進位 Protocol Buffers 編碼、HTTP/2 多路復用、強型別 IDL、雙向 streaming。Quarkus 一流支援 gRPC：quarkus-grpc 擴充自動從 .proto 生成 Java 程式碼，讓你只要實作 service 介面即可，server 與 client 都完整支援。

版本 Quarkus 3.33 LTS · gRPC 1.65+ · Protobuf 3.x
預估閱讀 24 分鐘
更新 2026-05-16

gRPC vs REST：選型指南

考量REST（JSON）gRPC（Protobuf）
效能（payload 大小）中等（JSON 文字）✅ 優秀（binary，通常小 3–10x）
型別安全靠文件/OpenAPI✅ IDL 強制（.proto）
瀏覽器相容✅ 原生⚠ 需要 gRPC-Web proxy
Streaming⚠ SSE（單向）✅ 雙向 streaming 原生
跨語言✅ 任何語言✅ protoc 生成各語言
適合公開 API、瀏覽器微服務內部通訊、高吞吐、streaming

設定

bash
quarkus extension add grpc

定義 .proto

protobuf · src/main/proto/catalog.proto
syntax = "proto3";

option java_package = "com.example.catalog.grpc";
option java_multiple_files = true;

package catalog;

// 服務定義
service CatalogService {
  // Unary RPC
  rpc GetProduct(GetProductRequest) returns (ProductResponse);

  // Server streaming（推送多個結果）
  rpc SearchProducts(SearchRequest) returns (stream ProductResponse);

  // Bidirectional streaming
  rpc WatchInventory(stream InventoryRequest) returns (stream InventoryUpdate);
}

message GetProductRequest {
  int64 id = 1;
}

message SearchRequest {
  string query = 1;
  int32 max_results = 2;
}

message ProductResponse {
  int64 id = 1;
  string name = 2;
  double price = 3;
  string category = 4;
}

message InventoryRequest {
  repeated string skus = 1;
}

message InventoryUpdate {
  string sku = 1;
  int32 quantity = 2;
  string status = 3;
}

build 後自動在 target/generated-sources/grpc/ 生成 Java 程式碼。

gRPC Server 實作

Java · gRPC Service 實作
import io.quarkus.grpc.GrpcService;
import io.smallrye.mutiny.Multi;
import io.smallrye.mutiny.Uni;

@GrpcService
public class CatalogServiceImpl implements CatalogService {

    @Inject ProductRepository productRepo;

    // Unary：回傳單一結果
    @Override
    public Uni<ProductResponse> getProduct(GetProductRequest request) {
        return productRepo.findById(request.getId())
            .map(p -> ProductResponse.newBuilder()
                .setId(p.id())
                .setName(p.name())
                .setPrice(p.price().doubleValue())
                .setCategory(p.category())
                .build());
    }

    // Server Streaming：回傳多個結果（搜尋）
    @Override
    public Multi<ProductResponse> searchProducts(SearchRequest request) {
        return productRepo.search(request.getQuery(), request.getMaxResults())
            .map(p -> ProductResponse.newBuilder()
                .setId(p.id())
                .setName(p.name())
                .build());
    }

    // Bidirectional Streaming：訂閱庫存更新
    @Override
    public Multi<InventoryUpdate> watchInventory(Multi<InventoryRequest> requests) {
        return requests
            .flatMap(req -> inventoryService.watchSkus(req.getSkusList()))
            .map(update -> InventoryUpdate.newBuilder()
                .setSku(update.sku())
                .setQuantity(update.quantity())
                .build());
    }
}

gRPC Client

Java · 注入 gRPC Client
import io.quarkus.grpc.GrpcClient;

@ApplicationScoped
public class InventoryService {

    @GrpcClient("catalog")       // 對應 application.properties 中的設定
    CatalogService catalogClient; // 自動生成的 Mutiny stub

    public Uni<ProductResponse> getProduct(Long id) {
        return catalogClient.getProduct(
            GetProductRequest.newBuilder().setId(id).build());
    }

    public Multi<ProductResponse> search(String query) {
        return catalogClient.searchProducts(
            SearchRequest.newBuilder().setQuery(query).setMaxResults(10).build());
    }
}

// application.properties
// quarkus.grpc.clients.catalog.host=catalog-service
// quarkus.grpc.clients.catalog.port=9000

gRPC Interceptor（認證、日誌）

Java · Server Interceptor（驗 token）
import io.grpc.*;
import io.quarkus.grpc.GlobalInterceptor;

@GlobalInterceptor          // 套用到所有 gRPC services
@ApplicationScoped
public class AuthInterceptor implements ServerInterceptor {

    static final Metadata.Key<String> AUTH_KEY =
        Metadata.Key.of("authorization", Metadata.ASCII_STRING_MARSHALLER);

    @Override
    public <Req, Resp> ServerCall.Listener<Req> interceptCall(
        ServerCall<Req, Resp> call, Metadata headers,
        ServerCallHandler<Req, Resp> next) {

        String token = headers.get(AUTH_KEY);
        if (token == null || !isValid(token)) {
            call.close(Status.UNAUTHENTICATED.withDescription("Invalid token"), new Metadata());
            return new ServerCall.Listener<>() {};
        }
        return next.startCall(call, headers);
    }

    private boolean isValid(String token) {
        return token.startsWith("Bearer ") && jwtValidator.validate(token.substring(7));
    }
}

同時提供 gRPC + REST

Quarkus 支援 gRPC-HTTP 轉碼（transcoding）── 同一個 service 同時提供 gRPC 和 REST/JSON endpoint：

protobuf · 加 HTTP annotation
import "google/api/annotations.proto";

service CatalogService {
  rpc GetProduct(GetProductRequest) returns (ProductResponse) {
    option (google.api.http) = {
      get: "/api/products/{id}"  // 同時提供 REST 路徑
    };
  }
}

本章小結

  • gRPC 適合微服務內部高效通訊；REST/JSON 適合公開 API 和瀏覽器。
  • Protocol Buffers：強型別 IDL，binary 編碼，通常比 JSON 小 3–10 倍。
  • 四種 RPC 模式：Unary / Server Streaming / Client Streaming / Bidirectional Streaming。
  • @GrpcService：實作 .proto 生成的介面，Quarkus 自動啟 gRPC server（預設 port 9000）。
  • @GrpcClient：注入 Mutiny stub，自動 reactive。
  • @GlobalInterceptor：認證、MDC 日誌等橫切面。
  • gRPC transcoding：同一 service 同時支援 gRPC 和 REST/JSON，client 自由選擇。
  • Quarkus gRPC 支援 OTel trace 自動傳播 ── 跨語言 trace 串接。
