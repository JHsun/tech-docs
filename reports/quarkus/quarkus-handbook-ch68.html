附錄 D：問題排查指南

Quarkus 最常見的啟動失敗、Runtime 問題、Native build 錯誤的診斷與解決方案速查，附常用診斷指令。

版本 Quarkus 3.33 LTS
更新 2026-05-16

啟動問題

症狀原因解法
Ambiguous dependency兩個同型別無 Qualifier 的 bean加 @Named 或自訂 Qualifier
Unsatisfied dependencyBean 被 Unused Removal 刪除加 @Unremovable
Port already in use上一個進程未關kill -9 $(lsof -ti:8080)
Dev Services 啟動失敗Docker 未啟動啟動 Docker / Podman

Runtime 問題

症狀原因解法
Vert.x blocked threadEvent loop 執行了阻塞操作加 @Blocking 或 @RunOnVirtualThread
OOMKilled（K8s）JVM Heap 超 container limit-XX:MaxRAMPercentage=75
Connection pool 排隊pool max-size 太小增大 quarkus.datasource.jdbc.max-size
@Transactional 無效（private）proxy 無法攔截 private改 public；Quarkus 3.x build failure
Kafka consumer 消費越來越慢void method 無 backpressure改回傳 Uni<Void>
NPE 在 @Inject 欄位直接 new 建立了物件讓 CDI 建立 bean，不要 new MyService()

Native Build 問題

錯誤原因解法
ClassNotFoundException at runtime未被 reachability 分析涵蓋加 @RegisterForReflection
Missing resourceclasspath resource 未包進 binaryquarkus.native.resources.includes=**/*.sql
Build OOM記憶體不足-Dquarkus.native.native-image-xmx=8g
ELF format 錯誤macOS 上 build 部署到 Linux加 -Dquarkus.native.container-build=true

診斷指令速查

bash
# CDI bean 清單
open http://localhost:8080/q/dev-ui/io.quarkus.arc.quarkus-arc/beans

# 健康狀態
curl http://localhost:9000/q/health

# Metrics
curl http://localhost:9000/q/metrics

# Virtual Thread pinning 偵測
java -Djdk.tracePinnedThreads=full -jar quarkus-run.jar

# 依賴樹
./mvnw dependency:tree | grep -A2 "com.example"
