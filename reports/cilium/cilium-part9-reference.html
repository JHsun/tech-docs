2. cilium CLI 速查（本機）

整體狀態與版本

cluster 整體健康
cilium status --verbose
等所有元件 ready（CI / 自動化用）
cilium status --wait
CLI 與 image 版號
cilium version

安裝 / 升級 / 解除

一鍵安裝（內部走 Helm）
cilium install --version 1.19.3 --set kubeProxyReplacement=true
升級到指定版本
cilium upgrade --version 1.19.3
解除（會刪 DaemonSet、ConfigMap、CRD）
cilium uninstall

connectivity 測試

完整 connectivity test（建測試 namespace）
cilium connectivity test
指定測試 namespace
cilium connectivity test --test-namespace cilium-test
跨 cluster 測試（ClusterMesh）
cilium connectivity test --multi-cluster <dst-context>
performance benchmark
cilium connectivity perf --duration 30s

Hubble

啟用 Hubble 含 UI
cilium hubble enable --ui
port-forward Hubble Relay 到 localhost:4245
cilium hubble port-forward&
開瀏覽器看 Hubble UI
cilium hubble ui

ClusterMesh

啟用 ClusterMesh
cilium clustermesh enable
建立兩 cluster 雙向連線
cilium clustermesh connect --context kind-c1 --destination-context kind-c2
看 mesh 狀態
cilium clustermesh status --wait
1.19 找出受 local-cluster 預設影響的 policy
cilium clustermesh inspect-policy-default-local-cluster --all-namespaces

BGP

看 BGP peer 與 session 狀態
cilium bgp peers
已宣告路由
cilium bgp routes advertised ipv4 unicast
收到的路由
cilium bgp routes available ipv4 unicast

診斷打包

產生完整 sysdump（GitHub issue 用）
cilium sysdump --output-filename cilium-sysdump-$(date +%F)
限制 log 範圍
cilium sysdump --logs-since=2h --node-list node1,node2

3. cilium-dbg 速查（agent pod 內）

所有指令都要 kubectl -n kube-system exec ds/cilium -- cilium-dbg ...。下面省略前綴只列 subcommand。

3.1 status / endpoint

該 node agent 詳細狀態
cilium-dbg status --verbose
列該 node 上所有 endpoint
cilium-dbg endpoint list
看單一 endpoint 詳細
cilium-dbg endpoint get <id>
endpoint health
cilium-dbg endpoint health <id>
針對 endpoint 開 debug
cilium-dbg endpoint config <id> Debug=true
輸出 jsonpath（程式化處理）
cilium-dbg endpoint list -o jsonpath='{[*].id}'

3.2 policy

看該 node 套用的所有 policy
cilium-dbg policy get
看 policy 用到的 selectors
cilium-dbg policy selectors
模擬決策（不發實際請求）
cilium-dbg policy trace --src-identity 12345 --dst-identity 67890 --dport 80/TCP
看實際 policy enforcement state
cilium-dbg policy enforcement

3.3 BPF maps

列所有 BPF map
cilium-dbg map list
dump 特定 map（如 ipcache）
cilium-dbg map get cilium_ipcache
看 map 即時變動 event
cilium-dbg map events cilium_ipcache
conntrack 表（global）
cilium-dbg bpf ct list global
NAT 表
cilium-dbg bpf nat list
policy map（per endpoint）
cilium-dbg bpf policy get <endpoint-id>
ipcache：IP ↔ identity 對照
cilium-dbg bpf ipcache list
tunnel 表（cluster node 列表）
cilium-dbg bpf tunnel list

3.4 service / LB

看所有 K8s Service 與 backend
cilium-dbg service list
看 BPF LB map（取代 kube-proxy）
cilium-dbg bpf lb list
查 service 詳細
cilium-dbg service get <svc-id>

3.5 identity / kvstore

列 cluster 內所有 identity
cilium-dbg identity list
查特定 identity 詳細（labels）
cilium-dbg identity get <identity-id>
kvstore 內容（外部 etcd 模式）
cilium-dbg kvstore get <key>

3.6 monitor / FQDN

看 BPF datapath event（verbose）
cilium-dbg monitor -v
只看 drop
cilium-dbg monitor --type drop
針對特定 endpoint
cilium-dbg monitor --related-to <endpoint-id>
policy verdict 專屬
cilium-dbg monitor --type policy-verdict
DNS proxy 學到的 FQDN cache
cilium-dbg fqdn cache list

3.7 BGP / Encryption / ClusterMesh

該 node 的 BGP peer 狀態
cilium-dbg bgp peers
BGP 接收到的路由
cilium-dbg bgp routes available
驗證 encryption 啟用狀態
cilium-dbg encrypt status
ClusterMesh 自動排查
cilium-dbg troubleshoot clustermesh

輸出格式

JSON 輸出
cilium-dbg endpoint list -o json
jsonpath
cilium-dbg endpoint list -o jsonpath='{range [*]}{@.id}{"="}{@.status.identity.id}{"\n"}{end}'

4. hubble CLI 速查

連線設定

port-forward Relay（背景）
cilium hubble port-forward&
確認連線
hubble status

觀察 flow

最近 20 個 flow
hubble observe --last 20
即時 follow
hubble observe --follow
特定 pod
hubble observe --pod default/myapp-7f6cd
特定 label 群組
hubble observe --label app=billing
特定 namespace
hubble observe --namespace production
source ↔ destination
hubble observe --from-namespace prod --to-namespace db --port 5432

verdict / 協定篩選

只看 dropped
hubble observe --verdict DROPPED
只看 L7 HTTP
hubble observe --type l7 --protocol http
DNS 流量
hubble observe --type l7 --protocol dns
特定 HTTP method / path
hubble observe --http-method POST --http-path "/api/v1/.*"
特定 HTTP status
hubble observe --http-status "5.."
特定 identity
hubble observe --identity 12345
加密 / 未加密流量
hubble observe --encrypted

輸出格式

JSON Lines（給 jq）
hubble observe --output json | jq
JSON Protobuf（給工具）
hubble observe --output jsonpb --last 1000 > flows.jsonl
含詳細 raw filter 輸出
hubble observe --output dict --print-raw-filters

實用一行

bash
# 最常被擋的 src → dst 對
hubble observe --verdict DROPPED --last 5000 --output json | \
  jq -r '"\(.source.namespace)/\(.source.pod_name) -> \(.destination.namespace)/\(.destination.pod_name)"' | \
  sort | uniq -c | sort -rn | head

# HTTP 5xx 比例
hubble observe --http-status "5.." --last 5000 --output json | \
  jq -r '.l7.http.code' | sort | uniq -c

# top DNS query
hubble observe --type l7 --protocol dns --last 5000 --output json | \
  jq -r '.l7.dns.query' | sort | uniq -c | sort -rn | head

5. cilium-bugtool（單 node 診斷）

在該 agent pod 內產生診斷包
kubectl -n kube-system exec ds/cilium -- cilium-bugtool
複製 archive 到本機
kubectl cp kube-system/cilium-xxxxx:/tmp/cilium-bugtool-DATE.tar.gz ./bugtool.tar.gz
用 tar.gz 格式（小）
cilium-bugtool --archivetype=tgz
指定額外 command 收集
cilium-bugtool --exec-commands="kubectl describe nodes,ip route show"

archive 內容大致包含：cilium-agent log、BPF map dump、iptables、ip route、host kernel info、Cilium config、所有 endpoint 詳細。對外 share 前先檢查敏感資訊。

7. Key-Value Store Layout

當 identityAllocationMode=kvstore 時，Cilium 用 etcd 儲存 cluster 狀態。瞭解 layout 有助於排查 kvstore 問題。

Key Prefix用途
cilium/state/identities/v1/identity 對照（identity ID → labels）
cilium/state/ip/v1/IP → endpoint 對照
cilium/state/nodes/v1/cluster nodes
cilium/state/services/v1/K8s services
cilium/cache/services/v1/service backend cache
cilium/.heartbeatquorum 健康檢查

Leases 與 GC

Cilium 為大多數 key 加上 lease（TTL），當 cilium-agent 離線時 lease 過期，key 被自動清除。每個 agent 維護一個 lease；ClusterMesh 場景下還有 cross-cluster 同步 lease。

限制與注意

  • kvstore 不可用 → identity allocation 卡住 → 新 pod 拿不到 identity → policy 不能套
  • etcd 失去 quorum（> ⌊n/2⌋ 節點 down）→ kvstore 不可寫 → 同上後果
  • 不要手動編輯 kvstore key，所有變動透過 cilium-agent

除錯

bash
# 看 cilium 與 kvstore 連線
kubectl -n kube-system exec ds/cilium -- cilium-dbg status | grep KVStore

# 直接查 kvstore key
kubectl -n kube-system exec ds/cilium -- cilium-dbg kvstore get cilium/state/nodes/v1/ --recursive

# 看 lease 狀態
kubectl -n kube-system exec ds/cilium -- cilium-dbg status --verbose | grep lease

8. Glossary（術語對照）

Endpoint
Cilium 的網路抽象單位，對應一個 Pod（或非 K8s 場景的容器）。每個 endpoint 有唯一 ID（numeric）。
Identity
一組 label 的 numeric hash。Pod 的 label 改變，identity 也會變。Policy 在 datapath 比對的是 identity 不是 IP。
Labels
identify 一個 endpoint 的 key=value pair。Cilium 把 K8s pod label、namespace、container label、保留 label 全部合在一起當 identity 依據。
Security Identity
identity 的別稱，強調其安全用途。Reserved identities 包括 world / host / remote-node / kube-apiserver / ingress / health / unmanaged / init / cluster / all。
Reserved Identity
Cilium 內建特殊 identity，自動分配給特定類型 endpoint（host process、外部 world 等）。
CNI (Container Network Interface)
K8s 規範的網路 plugin 介面。Cilium 提供 cilium-cni binary 實作 CNI。
eBPF (extended Berkeley Packet Filter)
Linux kernel 內可掛 sandboxed program 的機制。Cilium datapath 完全建構在 eBPF 上。
BPF Map
kernel 與 userspace 共享的資料結構。Cilium 用各種 map 存 identity、policy、service backend、conntrack 等。
TC (Traffic Control) Hook
Linux 網路堆疊中的封包過濾掛點，位於 device queue。Cilium 把 BPF program 主要掛在 TC ingress / egress 上。
XDP (eXpress Data Path)
BPF 在 NIC driver 層的掛點，比 TC 更早攔截封包。Cilium 用於 NodePort/LB 加速。
tcx
新一代 BPF link 機制（kernel 6.6+），取代 tc-bpf 的舊 API。1.19 支援。
netkit
kernel 6.8+ 引入的新 L3 設備類型，專為 BPF 設計。1.19 Beta 用作 veth 替代。
VXLAN
L2-over-L4 封裝協定，UDP 8472。Cilium 預設 overlay。
Geneve
支援 metadata TLV 的封裝協定，UDP 6081。Cilium 選用之一。
Native Routing
不封裝，Pod IP 直接走 underlay 路由表。
Direct Routing
Native routing 的舊名稱。
IPAM
IP Address Management。Cilium 多種模式：cluster-pool、kubernetes、multi-pool、ENI、Azure。
Masquerading / SNAT
把 Pod 出向流量的 src IP 改成 node IP，讓外部能 reply。Cilium 用 BPF 取代 iptables NAT。
Conntrack (CT)
連線追蹤，每個 5-tuple 一個 entry。Cilium 用 BPF map 實作（不是 nf_conntrack）。
MTU (Maximum Transmission Unit)
單一 packet 最大 size。Overlay 加 ~50 bytes 封裝，underlay MTU 1500 → pod MTU 通常 1450。
kube-proxy
K8s 內建 Service LB，用 iptables/IPVS。Cilium 可完全取代（kubeProxyReplacement=true）。
Socket-LB
Cilium 在 connect()/sendto() syscall hook 做 service translation，cluster 內呼叫零 datapath 開銷。
DSR (Direct Server Return)
LB mode 之一，backend 直接回 client（不經 LB node）。保留 client IP，但需 native routing。
Maglev hashing
consistent hashing 算法。backend 變動時最多 1% 連線重分配。
CNP (CiliumNetworkPolicy)
Cilium 擴充版 NetworkPolicy，namespace scope，支援 L3/L4/L7/deny/FQDN/SNI。
CCNP (CiliumClusterwideNetworkPolicy)
cluster scope 版 CNP，常用於 host policy 與全域規則。
Policy Enforcement Mode
default / always / never。default 沒選到就放行；always 沒選到就 deny。
idempotent
同樣輸入多次執行結果一致。Cilium policy 套用是 idempotent。
FQDN (Fully Qualified Domain Name)
完整域名（含 root dot 概念）。Cilium 用 DNS proxy 學 FQDN 到 IP 對照。
SNI (Server Name Indication)
TLS ClientHello 內帶的目的 hostname。Cilium 可不解密就比對。
Hubble
Cilium 的可觀測性元件。三件式：Hubble in agent / Hubble Relay / Hubble UI。
Flow
Hubble 對單一連線/封包事件的記錄單位，含 source/destination/verdict/L7 等資訊。
Verdict
Hubble flow 的判決：FORWARDED / DROPPED / ERROR / AUDIT / REDIRECTED / TRACED。
Hubble Relay
cluster-wide Hubble gateway，聚合所有 node 的 Hubble flow。
ClusterMesh
把多個 K8s cluster 串成一張網。每 cluster 有 clustermesh-apiserver。
KVStoreMesh
1.16+ 預設啟用的 ClusterMesh 同步優化，連線數從 N×M 降到 M。
Global Service
Service 加 service.cilium.io/global: "true"，跨 cluster 找 backend。
BGP (Border Gateway Protocol)
路由協定。Cilium 內建 BGP speaker（GoBGP），可宣告 PodCIDR / Service VIP。
L2 Announcement
用 ARP（IPv4）/ NDP（IPv6）讓 Service VIP 在 LAN 可達。無 BGP 環境替代方案。
Egress Gateway
把特定 pod 出向流量強制走指定 node，用固定 SNAT IP。
Envoy
L7 proxy。Cilium 用 per-node DaemonSet（cilium-envoy）做 L7 policy、Ingress、Gateway。
Ingress Controller
處理 K8s Ingress 資源的 controller。Cilium 內建 ingressClassName: cilium。
Gateway API
K8s 新一代 Ingress 規範，role-oriented、protocol-aware。Cilium 1.14+ Stable。
CEC (CiliumEnvoyConfig)
讓使用者直接寫 Envoy 原生 config，做 L7 traffic management（rate limit、retry、CB）。
TPROXY
iptables target，把流量透明導向 local socket，保留原 src IP。Cilium Ingress 用它保留 client IP。
WireGuard
kernel-native VPN 協定，UDP 51871。Cilium Transparent Encryption 推薦。
IPsec
傳統業界 VPN 標準。Cilium Transparent Encryption 另一選項，FIPS 完整支援。
SPIFFE / SPIRE
service identity 與 short-lived cert 標準。Cilium mTLS 採用。
Ztunnel
Istio Ambient 的 per-node L4 proxy。1.19 Cilium 整合 Beta。
playbook
SRE 領域指可重複執行的 runbook。本手冊各章 lab 即可作為 playbook。
handler
Cilium agent 內處理特定 K8s event / API 請求的函數模組。
FQCN
Ansible 術語（Fully Qualified Collection Name）。在 Cilium 文件不常見，但跨工具混用時請注意上下文。
