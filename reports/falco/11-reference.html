11.2CLI Arguments 完整參數

執行 falco --help 可得最完整清單，這裡列出實務最常用的。

啟動與設定

參數用途範例
-c, --conf-file指定 config 檔-c /etc/falco/falco.yaml
-r, --rules指定 rules 檔（可多次）-r my.yaml -r extra.yaml
--validate只驗證 rule 不啟動--validate my.yaml
-V, --version顯示版本-V
--dry-run啟動但不真的處理 syscallconfig 測試

事件來源與 Driver

參數用途
-o, --option覆寫單一 config 選項，-o output.json=true
--modern-bpf強制使用 modern eBPF driver
--cri指定 CRI socket
--disable-source停用特定 source（如 syscall）
--enable-source啟用特定 source

規則控制

參數用途
-t, --tag只跑帶該 tag 的 rule
-T, --disabled-tag停用該 tag 的 rule
-D, --disable-rule停用單一 rule
-e, --enable-rule啟用單一 rule

Capture / Replay

參數用途
-e <file>從 capture file 重播
--capture-file=<path>錄製到檔案
--capture-duration=<sec>錄製多久

輸出與 List 命令

參數用途
--list-events列出支援的 events
--list-fields列出所有可用欄位
--list-plugins列出已載入的 plugins
--list-syscalls列出當前載入的 syscall set
--markdown輸出為 markdown 表（搭配 --list-*）
-L, --list列出當前載入的 rules
-N, --names-only只顯示名稱

11.6常用 Default Macros

官方 ruleset 內預定義的 macros。寫 rule 時優先重用這些。

Macro意義
container事件發生在容器內
spawned_processexecve / execveat 事件
open_write檔案以寫入模式打開
open_read檔案以讀取模式打開
never_true恆假；用於佔位待 override
always_true恆真
bin_dir檔案位於 /usr/bin、/usr/sbin、/bin、/sbin
etc_dir檔案位於 /etc
shell_procs程序屬於 shell（bash, sh, zsh...）
package_mgmt_procs程序是 apt / yum / dnf / pip 等
known_drop_and_execute_from_container合法的下載執行行為
user_known_*一系列等待使用者覆寫的白名單

11.7Supported Syscalls（選錄）

Falco 支援數百個 syscall。下面是寫 rule 最常用到的分類。 完整清單由 falco --list-events --markdown 產生（v0.43 ~400 個）。

程序與執行

execve、execveat、clone、clone3、fork、vfork、setuid、setgid、capset、prctl、setns、unshare、execveat、kill

檔案與 I/O

open、openat、openat2、creat、close、read、write、pread64、pwrite64、unlink、unlinkat、rename、renameat、mkdir、mkdirat、rmdir、symlink、symlinkat、link、linkat、chmod、fchmod、chown、fchown

網路

socket、bind、connect、listen、accept、accept4、sendto、recvfrom、sendmsg、recvmsg、sendmmsg、recvmmsg、shutdown

容器與 Namespace

setns、unshare、pivot_root、mount、umount、umount2

Capability

capset、capget、prctl（with PR_CAP_AMBIENT等）

11.8Output 模板常用 Field 速查

寫 output 時最常嵌入的欄位組合。

Process info 套組

output snippet
output: >
  (user=%user.name user_loginuid=%user.loginuid
   process=%proc.name parent=%proc.pname
   cmdline=%proc.cmdline exe=%proc.exe pid=%proc.pid)

Container + K8s 套組

output snippet
output: >
  (container_id=%container.id container=%container.name
   image=%container.image.repository tag=%container.image.tag
   k8s_ns=%k8s.ns.name k8s_pod=%k8s.pod.name)

File / Path 套組

output snippet
output: >
  (file=%fd.name path=%fs.path.name dir=%fd.directory
   evt_type=%evt.type)

Network connection 套組

output snippet
output: >
  (connection=%fd.name proto=%fd.l4proto
   client=%fd.cip:%fd.cport server=%fd.sip:%fd.sport
   server_name=%fd.sip.name)

11.9Changelog 重點摘要（v0.36 ~ v0.43）

過去 8 個 minor release 的重要變動，重點放在影響 rule / config 行為的部分。

v0.43 2026-01-28（v0.43.1: 2026-04-09）

  • Falco Operator 0.2.0 正式 production-ready（2026-03 釋出）
  • gRPC API 整段標記 deprecated，未來移除
  • Legacy eBPF probe 標記 deprecated
  • gVisor engine 標記 deprecated
  • GPG key rotation（2026-01-17）—— 舊節點升級前須匯入新 key
  • capture feature 改進（錄製 .scap 再重播）
  • EKS Add-on 上線（AWS-validated）

v0.42 2025-10

  • "drop-enter initiative"：預設只處理 syscall exit 事件，效能 +30%
  • evt.dir = >（enter 方向）開始不匹配；emit warning
  • outputs queue 完整實作（解耦下游故障）
  • Falco Operator 0.1.0 (technical preview)

v0.41 2025-07

  • Container metadata 邏輯獨立成 container plugin
  • k8s-metacollector：集中收集 K8s metadata 的新元件
  • Plugin SDK Go 進入 stable

v0.40 2025-04

  • Modern eBPF driver 預設啟用
  • 多項 rule maturity 重新分類
  • 新增 fs.path.* 進階 transformer

v0.39 2024-10

  • 移除 %container.info output placeholder（用具體欄位取代）
  • Prometheus exporter 正式 stable
  • 引入更多 maturity tags 控制機制

v0.38 2024-06

  • 內建 Prometheus metrics exporter（取代 falco-exporter）
  • Webserver 新增 /metrics endpoint
  • rules counters per-rule metrics

v0.37 2024-03

  • enabled: true 標記為要避免；改用 override 區塊
  • 新增 rule_matching: all 模式
  • 強化 falcoctl artifact follow

v0.36 2023-12

  • 新增 fs.path.* 統一路徑欄位族
  • 新增 fd.sip.name 等 hostname 反解欄位
  • Style Guide 重大更新
  • 引入 rule_matching 概念

11.10Exit Codes 與環境變數

Exit Codes

Code意義
0正常退出
1一般錯誤（rule 解析失敗 / config 錯誤）
2啟動 failure（driver 載入失敗等）
3signal 觸發退出 (SIGINT/SIGTERM)
非 0 由 syscall_event_drops.actions: [exit] 觸發drop 過量自殺

環境變數

變數說明
FALCO_BPF_PROBE強制使用 legacy eBPF probe（路徑或空字串）
HOST_ROOT非 / 的主機根目錄（container 部署用，預設 /host）
SKIP_DRIVER_LOADER跳過 driver loader（已預先載入時）
FALCOCTL_CONFIG覆寫 falcoctl config 路徑
