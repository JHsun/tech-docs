開發者指南

想把 Falco 接上新的事件來源、為現有 source 加自訂欄位？本章從 source 編譯開始， 走過 Plugin SDK (Go / C++ / Rust)、完整 plugin 範例、發佈與註冊到 OCI registry 的流程。

10.1開發者地圖

Falco 對開發者開放三個面向：從 source 編譯 Falco 自身、寫 Plugin、 以及（已 deprecated 的）gRPC API。實務上 99% 的開發者只關心 Plugin。

    B -->|改 Falco 核心邏輯| E[從 source build]
    B -->|外部 client 接 alert| F[HTTP / falcosidekick]

💡
大多數情境用 Plugin 就夠：從 source 編譯只在「改 Falco 核心」或「貢獻 upstream patch」時需要。 若只是想新增 event source 或欄位，Plugin 是正解。

10.2從 Source 編譯 Falco

需要修 Falco 本體（rare）、向 upstream 送 patch、或在不支援架構上自編譯時。

環境需求

  • CMake ≥ 3.18
  • GCC ≥ 9 或 Clang ≥ 12
  • Go ≥ 1.22（部分元件）
  • Linux kernel headers
  • ~ 10 GB 磁碟空間（含 dependencies build）

完整編譯流程

bash · build from source
# 1. clone
git clone https://github.com/falcosecurity/falco.git
cd falco
git checkout 0.43.1

# 2. 建 build dir
mkdir -p build && cd build

# 3. configure
cmake -DUSE_BUNDLED_DEPS=ON \
      -DBUILD_DRIVER=ON \
      -DBUILD_BPF=ON \
      ..

# 4. compile (用所有 CPU)
make -j$(nproc) falco

# 5. 跑跑看
sudo ./userspace/falco/falco -c ../falco.yaml

# 6. 編譯 .deb / .rpm package
make package
⚠️
首次 build 耗時長：USE_BUNDLED_DEPS=ON 會把 libsinsp、libscap、cmake-fetch 全部下載並編譯， 在普通開發機通常 30-60 分鐘。後續增量編譯 < 5 分鐘。

進階：跑 unit test

bash · run tests
make tests
ctest --output-on-failure

10.3Plugin SDK 概觀（Go / C++ / Rust）

Falco 提供三種 SDK。Go 是社群最常用（90% 官方 plugins 都用 Go）；C++ 是原生選擇；Rust 適合追求效能與記憶體安全。

SDKRepo適合版本
Gofalcosecurity/plugin-sdk-go大多數情境；快速開發v0.7.5+
C++falcosecurity/plugin-sdk-cpp最低 overhead；與 Falco 核心同語言進行中
Rustfalcosecurity/plugin-sdk-rs記憶體安全；新興偏好incubating

需要實作的最小 interface

不同 plugin 類型需要實作不同 interface。下面是 Source plugin（提供 events）的：

go · Source plugin interface
// sdk/plugins/source
type Plugin interface {
    Info() *sdk.Info
    Init(config string) error
    Open(params string) (source.Instance, error)
}

// Instance interface（每個 open 都建立一個 instance）
type Instance interface {
    NextBatch(p sdk.PluginState, evt sdk.EventWriters) (int, error)
    Close()
}

Extractor plugin（為現有事件加欄位）：

go · Extractor plugin interface
// sdk/plugins/extractor
type Plugin interface {
    Info() *sdk.Info
    Init(config string) error
    Fields() []sdk.FieldEntry
    Extract(req sdk.ExtractRequest, evt sdk.EventReader) error
}

10.4從零寫一個 Plugin（Go，完整範例）

這節走過一個完整的 source + extractor 雙重 capability plugin——把 RSS feed 當成 Falco 的事件來源。 雖然不實用，但 illustrate 了全部關鍵 API。

建議的 repo 結構

tree
my-rss-plugin/
├── LICENSE
├── Makefile
├── README.md
├── go.mod
├── go.sum
├── pkg/
│   └── rss.go              # 核心邏輯
├── plugin/
│   └── main.go             # 註冊入口（產出 .so）
└── rules/
    └── rss_rules.yaml      # 該 plugin 對應的範例 rules

初始化 module

bash · go mod init
mkdir my-rss-plugin && cd my-rss-plugin
go mod init github.com/yourorg/my-rss-plugin

go get github.com/falcosecurity/plugin-sdk-go@v0.7.5
go get github.com/mmcdole/gofeed     # RSS parser

定義 plugin 與 instance struct

pkg/rss.go
package rss

import (
    "encoding/json"
    "fmt"
    "io"
    "time"

    "github.com/mmcdole/gofeed"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk/plugins"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk/plugins/source"
)

// ========== Plugin (singleton) ==========
type Plugin struct {
    plugins.BasePlugin
    config PluginConfig
}

type PluginConfig struct {
    PollIntervalSec int `json:"poll_interval_sec"`
}

func (p *Plugin) Info() *sdk.Info {
    return &sdk.Info{
        ID:                  9999,                       // 必須註冊取得
        Name:                "rss",
        Description:         "RSS feed events for Falco",
        Contact:             "github.com/yourorg/my-rss-plugin",
        Version:             "0.1.0",
        EventSource:         "rss",
        RequiredAPIVersion:  "3.0.0",
    }
}

func (p *Plugin) Init(cfg string) error {
    p.config.PollIntervalSec = 60
    if cfg != "" {
        if err := json.Unmarshal([]byte(cfg), &p.config); err != nil {
            return fmt.Errorf("invalid init_config: %w", err)
        }
    }
    return nil
}

// ========== Instance (per open) ==========
type Instance struct {
    source.BaseInstance
    feedURL  string
    interval time.Duration
    parser   *gofeed.Parser
    seen     map[string]bool
}

func (p *Plugin) Open(params string) (source.Instance, error) {
    return &Instance{
        feedURL:  params,           // openParams = feed URL
        interval: time.Duration(p.config.PollIntervalSec) * time.Second,
        parser:   gofeed.NewParser(),
        seen:     map[string]bool{},
    }, nil
}

// NextBatch — 主迴圈，產出事件
func (i *Instance) NextBatch(p sdk.PluginState, evts sdk.EventWriters) (int, error) {
    feed, err := i.parser.ParseURL(i.feedURL)
    if err != nil {
        return 0, sdk.ErrTimeout    // 失敗時暫停
    }

    n := 0
    for _, item := range feed.Items {
        if i.seen[item.GUID] {
            continue
        }
        i.seen[item.GUID] = true

        // 把 feed item 包成 JSON event
        b, _ := json.Marshal(map[string]string{
            "title":     item.Title,
            "link":      item.Link,
            "published": item.Published,
            "guid":      item.GUID,
        })

        w := evts.Get(n)
        w.SetTimestamp(uint64(time.Now().UnixNano()))
        if _, err := w.Writer().Write(b); err != nil && err != io.EOF {
            return n, err
        }
        n++
        if n >= evts.Len() {
            break
        }
    }
    return n, nil
}

func (i *Instance) Close() {}

新增 Extractor 能力（從 event JSON 拉欄位）

pkg/rss.go · extractor 部分
import (
    "encoding/json"
    "io"

    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk"
)

// 宣告該 plugin 提供哪些欄位
func (p *Plugin) Fields() []sdk.FieldEntry {
    return []sdk.FieldEntry{
        {Type: "string", Name: "rss.title",     Desc: "Feed item title"},
        {Type: "string", Name: "rss.link",      Desc: "Feed item URL"},
        {Type: "string", Name: "rss.guid",      Desc: "Feed item GUID"},
        {Type: "string", Name: "rss.published", Desc: "Publish timestamp"},
    }
}

// 對每個 event extract 欄位值
func (p *Plugin) Extract(req sdk.ExtractRequest, evt sdk.EventReader) error {
    buf, _ := io.ReadAll(evt.Reader())
    var data map[string]string
    if err := json.Unmarshal(buf, &data); err != nil {
        return err
    }

    switch req.Field() {
    case "rss.title":
        req.SetValue(data["title"])
    case "rss.link":
        req.SetValue(data["link"])
    case "rss.guid":
        req.SetValue(data["guid"])
    case "rss.published":
        req.SetValue(data["published"])
    }
    return nil
}

plugin/main.go — 註冊入口

plugin/main.go
package main

import (
    rss "github.com/yourorg/my-rss-plugin/pkg"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk/plugins"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk/plugins/extractor"
    "github.com/falcosecurity/plugin-sdk-go/pkg/sdk/plugins/source"
)

func init() {
    plugins.SetFactory(func() plugins.Plugin {
        p := &rss.Plugin{}
        source.Register(p)      // 註冊為 source
        extractor.Register(p)   // 同時註冊為 extractor
        return p
    })
}

func main() {}     // 必須有但保持空

  output: >
    New Falco blog: %rss.title - %rss.link (published %rss.published)
  priority: INFO
  source: rss
  tags: [news, custom]

10.5進階：Async Events、Open Params 校驗、State

Async Events（v0.43 完整支援）

對於高 throughput 來源，NextBatch 阻塞模式會慢。改用 async event channel：

go · async pattern
type Instance struct {
    source.BaseInstance
    ch chan []byte
}

func (p *Plugin) Open(params string) (source.Instance, error) {
    i := &Instance{ch: make(chan []byte, 1000)}

    // 背景 goroutine 不停產出 event
    go func() {
        for {
            data := pollSomeSource()
            i.ch <- data
        }
    }()

    return i, nil
}

func (i *Instance) NextBatch(p sdk.PluginState, evts sdk.EventWriters) (int, error) {
    n := 0
    for n < evts.Len() {
        select {
        case data := <-i.ch:
            w := evts.Get(n)
            w.Writer().Write(data)
            n++
        case <-time.After(100 * time.Millisecond):
            return n, sdk.ErrTimeout
        }
    }
    return n, nil
}

Init Config 與 Open Params 校驗

用 JSON schema 描述 config，讓 Falco 啟動時就驗證：

go · schema 提供
func (p *Plugin) InitSchema() *sdk.SchemaInfo {
    return &sdk.SchemaInfo{
        Schema: `{
            "type": "object",
            "properties": {
                "poll_interval_sec": { "type": "integer", "minimum": 5 }
            },
            "required": ["poll_interval_sec"]
        }`,
    }
}

Plugin ID 申請

⚠️
重要：每個 source plugin 需要全球唯一的 ID（uint32）。 開發階段可用 9999 等大數，釋出前必須在 falcosecurity/plugins repo 開 PR 申請正式 ID。 ID 區段：1-999 官方保留；1000+ 開放申請。

10.7發佈與註冊到官方 Registry

寫完 plugin 後要讓社群能用，需要走兩條路：OCI artifact 打包發佈 + 註冊到 falcosecurity/plugins。

打包成 OCI artifact

bash · 打包推送
falcoctl registry login ghcr.io --username your-gh-user

# 推送 plugin .so
falcoctl registry push \
  ghcr.io/yourorg/rss-plugin:0.1.0 \
  --type plugin \
  --version 0.1.0 \
  librss.so

# 同時推送對應 rules
falcoctl registry push \
  ghcr.io/yourorg/rss-rules:0.1.0 \
  --type rulesfile \
  --version 0.1.0 \
  rules/rss_rules.yaml

# 從 registry 安裝測試
falcoctl artifact install ghcr.io/yourorg/rss-plugin:0.1.0

註冊到官方 plugins repo

送 PR 到 falcosecurity/plugins， 在 plugins/registry.yaml 加入你的 entry：

yaml · plugins/registry.yaml entry
- name: rss
  description: RSS feed events for Falco
  authors: yourorg
  contact: github.com/yourorg/my-rss-plugin
  maintainers:
    - name: Your Name
      email: you@example.com
  keywords: [rss, news, monitoring]
  url: https://github.com/yourorg/my-rss-plugin
  license: Apache-2.0
  reservedSources: [rss]
  capabilities:
    sourcing:
      supported: true
      id: 1234                              # 經 maintainer 配發
    extraction:
      supported: true
  ociRepository: ghcr.io/yourorg/rss-plugin
  rulesUrl: ghcr.io/yourorg/rss-rules

Maintainer review 檢查項

  • Plugin ID 唯一且在合法範圍
  • 必填欄位齊全
  • License 為 OSI 認可
  • 有可運作的範例 rule
  • README 完整，包含 init_config 與 open_params 範例
  • CI/release 流程有自動化

Maturity 流程

新 plugin 通常從 sandbox 起步，達到指標後升 incubating，再升 stable。 升級條件大致是：使用者數、單元測試覆蓋率、文件完整度、有 2+ active maintainer。

10.8gRPC API（已 deprecated）

過去 Falco 提供 gRPC server，讓外部 client 訂閱 alert。v0.43 標記 deprecated，未來移除。

🚨
不要再用 gRPC：所有新整合請走 HTTP + falcosidekick；若你有舊 gRPC client，計畫遷移到：
  • falcosidekick HTTP webhook：自己寫 endpoint 接 sidekick 的 JSON POST
  • falcosidekick Kafka / NATS：用 message bus 解耦
  • falcosidekick Webhook 自訂 output

遺留 gRPC client 範例（僅供參考）

若你必須在過渡期維護舊系統：

go · gRPC client (deprecated)
// 舊版做法，僅供舊系統遷移參考
import "github.com/falcosecurity/client-go/pkg/client"

c, err := client.NewForConfig(ctx, &client.Config{
    UnixSocketPath: "unix:///var/run/falco.sock",
})
defer c.Close()

stream, _ := c.OutputsClient().Sub(ctx)
for {
    resp, err := stream.Recv()
    if err != nil { break }
    fmt.Printf("Alert: %s\n", resp.Output)
}

10.9本章心智模型

  • 三條開發路徑：from source build / plugin / external integration
  • 99% 開發者只要寫 plugin；用 Go SDK 最快
  • Plugin 兩類能力：source（提供 events）+ extractor（提供 fields），可同時實作
  • 關鍵 interface：Info / Init / Open / NextBatch / Fields / Extract
  • 編譯成 .so 用 CGO_ENABLED=1 go build -buildmode=c-shared
  • 發佈走 OCI artifact + falcoctl；正式上線需註冊 plugin ID 到 official registry
  • gRPC API 已 deprecated，新整合一律走 HTTP
